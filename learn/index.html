Press room

One shell, two reading modes

Everything in this folder is shared. A tool that uses it is a folder with an index.html of about ninety lines — four regions and five script tags — a manifest.js, and a content/ directory with one folder per entry. There is no build step and no framework. Adding a chapter, a lens, an example or a style is dropping a folder and adding a line.

The transport, and why it is not fetch

Under file:// exactly one mechanism loads external data into a page: a classic <script src>. fetch, XMLHttpRequest, import() and module scripts all fail. These tools are opened by double-click from a checkout, so there is no fetch anywhere in this folder and there never will be. Data self-registers:

// manifest.js
Shell.registerManifest({ schemaVersion: 1, id: 'book-of-shaders', mode: 'course',
  sections: [ … ], entries: ['00-introduction', '01-what-is-a-shader', … ] });

// content/13-fbm/entry.js
Shell.registerEntry({ id: '13-fbm', index: '13', title: 'Fractal Brownian Motion',
  section: 'generative', status: 'canonical', lane: 'glsl',
  text: `<p>…</p>`, examples: [ { id: 'warped-fbm', code: `…` } ] });

The shell injects one classic script per entry at boot, in manifest order. The rail and any list view fill in as they land. An entry may also be given inline in the manifest as an object, for the six-line entry that does not need a folder.

Rules that are not negotiable

  • No fetch, no import(), no type="module", no CDN. Classic scripts only.
  • Never name a content file tool.json or package.json, and never name a folder dist/ or _site/ — the deploy copy filters those basenames at any depth.
  • Nothing touches iframe.contentDocument. Host and fragment talk by postMessage only.
  • The page is always light and says so: color-scheme on :root, a meta tag, and an explicit background on both html and body. The stage declares its own ground; the page never goes dark.
  • No accent hue in the chrome, no glass, no blur, no shadow. Failure is the FAULTS hatch plus the word FAILED.
  • A specimen is trimmed, not boxed: a neutral mat and four crop marks, and nothing the chrome draws touches the specimen’s edge.
  • A fragment declares its own type in content/_styles/<style>.css. The chrome’s two faces stop at the iframe boundary.
  • Every count on every page derives from entries.length. Nothing is typed by hand.

The adapter contract

A tool’s only code is a stage adapter. Two methods are required and the rest are optional:

{
  mount({ stage, bar, entry, example, query, params }),   // required
  unmount(),                                             // required — must be able to stop
  fillSource(entry, example),   // feeds the apparatus's source pane
  toggleRun(),                  // enables Space
  setParam(name, value),        // binds a declared parameter
  preview(el, entry, on),       // contact-sheet mount / evict
  onApparatusOpen()             // e.g. refill the pane
}

Keyboard

One map, both tools, guarded once centrally on INPUT, TEXTAREA and isContentEditable plus modifier pass-through. / search · j k ↓ ↑ entries · ← → examples · e apparatus · Space run · g i contact sheet · Esc out · ? the list. Esc works from inside a field, which is how you leave the editor.
