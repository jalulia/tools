Four surfaces

Two stocks and two marks, one material system. Paper and cloth are height fields; pen dots and a roller print into them through one ink chain; one sheet light rakes all of it. No gradient stands in for anything.

How to use the sheet
  1. Tune a plate — dials are grouped by what they change; a dot marks what you moved. Drag the light on any plate.
  2. Explore — wedge lays out a grid across two dials, pin · split compares against a frozen state, distance shows how the marks read from across a table.
  3. Take it — Output renders to a deck, a Figma frame or paper at true dpi, with ink plates and a height map; Lift gives a snippet that runs anywhere and a spec an agent can check.

Read

Ink on real stock under one raking light.

Shared causes
  • stock height field → relief shading · ink acceptance · starved pinholes · wicking · ink mottle
  • sheet light → paper relief · thread modeling · thread cast shadows · object shadows on the page
Pass order
  1. stock height (tooth · fibers · pits · formation | threads)
  2. albedo (paper L, thread dyes in OKLab)
  3. ink pressure (dot footprints | roller run-out) × mask
  4. acceptance vs height → starve → wick → film thickness
  5. color: Beer–Lambert film in linear light (or coverage mix)
  6. light: × Lambert shade × height shadow (once, last)
  7. page: object cast shadow, sRGB encode
FX-01

Stipple ramp

Tone made of whole pen dots. Value sets how many sites print (FM) or how big each dot is (AM); a blue-noise rank picks the sites. Each dot is crisp geometry whose edge the stock's tooth nudges — never softened.

Recipe

  1. Site lattice at the pitch (CSS px), jittered. Value field (linear · radial · noise) eased from → to.
  2. Screen: FM keeps a site when its blue-noise rank < value; AM keeps every site with radius ∝ √value; the dial interpolates. The mask is sampled at the site — dots are whole or absent.
  3. Each dot is geometry: a signed distance to an irregular nib outline (7 vertex radii), so its edge is always 1 device px of anti-aliasing — never a blur.
  4. The stock edits the edge: the distance is displaced by the stock height (edge rag), valleys inside the dot can starve, fibers wick a short way out. Film τ = thickness × pressure.
  5. Color: Beer–Lambert film in linear light (or a coverage mix). Ink B overprints by the same film product.
  6. Light last: × the stock's shading under the sheet light.

Limits

ParamRangeWhat happens
pitch< 1.2 pxsites merge into flat tone at 1× — the stipple stops reading as marks
dot radius< .3 pxbelow ~½ device px at 1× a dot is a gray pixel, not a mark
dot radius> ½ pitchdots fuse into a solid; FM loses its range
edge rag> .9 pxdots read as fuzz, not ink
selectionwhiteclumps and voids at low density

FX-02

Ink leaving paper

A solid that runs out. Roller pressure eases off across a warped edge; as it falls, only the peaks of the stock still touch the ink, so the run-out speckle is the paper's own tooth — with pinholes in its valleys and hairlines wicked along its fibers.

Recipe

  1. Pressure = dropoff curve of the signed distance to a warped edge line (stroke direction, transition width), × the mask.
  2. Ink chain: the stock height under the inked area (blended with film-splitting noise, clumped and streaked along the stroke) is ranked to percentiles; pressure P inks exactly the top P of the surface — peaks first.
  3. Starve: valleys below the threshold never take ink. Wick: fibers carry ink past the edge. Mottle: paper formation thins the film.
  4. Film thickness thins with pressure unless the film breaks up; color = Beer–Lambert film in linear light.
  5. Light last: × the stock's shading — the ink sits in the tooth, not on top of it.

Limits

ParamRangeWhat happens
transition< 4 pxreads as a hard vector edge — no run-out to see
break-up< .3the edge becomes a gradient — the "AI gradient" failure
stock bite< .3speckle stops following the paper — reads as digital dither
streak> 6marks read as scanlines unless the angle is off-axis

FX-03

Paper tooth

White stock that is not a screen. A height field — tooth, formation, laid fibers, pits — lit by the one sheet light. On white the relief can only take light away, so the paper reads through its shadows. FX-01 and FX-02 print into this exact field.

Recipe

  1. Height = fbm at the tooth scale (octaves, persistence = how fast detail drops off), reshaped by the distribution curve; blended with low-frequency formation.
  2. Fibers: curved capsules at a count per 100 × 100 px near the grain angle, raised into the height; pits: small depressions. Both also darken the albedo slightly.
  3. Normal from the height gradient → Lambert under the sheet light (azimuth + elevation from the light puck). Diffuse share vs ambient fill; the fill can be tinted.
  4. The same field is the stock for FX-01 and FX-02: its peaks take ink first, its valleys starve, its fibers wick.
  5. Mask = the sheet's cut or deckle edge; the sheet casts a contact + ambient shadow onto the page by the same light.

Limits

ParamRangeWhat happens
relief> .6 pxreads as stucco — the stock-filter emboss look
anisotropy< 1.3isotropic tooth reads as a 1999 paper filter
tooth scale< .8 pxcollapses into per-pixel noise — digital grain
fibers> 30 / 100 px²felt, not paper
light elevation< 15°every fiber becomes a hard ridge; ok for a raking-light study, not for a page

FX-04

Weave

Cloth built as cloth: warp and weft at their own counts, a real interlacing, slubbed and hairy threads, every float a raised body lit by the sheet light and casting into the gaps. A cut edge frays thread by thread. FX-01 and FX-02 can print onto it.

Recipe

  1. Warp columns and weft rows at their own counts (threads / 100 CSS px); each thread: jittered center, thickness, dye-lot L, fray length, accent.
  2. Interlacing decides the top thread per crossing; a float is the run where it stays on top. Height = cylinder across the thread × arch along the float; under-threads sit low; hair = fine noise along the thread.
  3. Albedo in OKLab: under-thread, then top thread by AA coverage; accent as flecks (single floats, as in the source) or whole threads.
  4. Light: Lambert from the height gradient + a height-field shadow march toward the sheet light, so floats shade into the gaps; ambient occlusion darkens the gaps.
  5. Cut: the mask's signed distance plus each thread's own fray length — threads end raggedly, not on a line. The swatch casts onto the page.

Limits

ParamRangeWhat happens
count> 50 /100 px at 1×threads under 2 CSS px alias against a 1× display — moiré (fine on 2×/3×)
count< 18 /100 pxthreads over ~5 px read as a woven-texture graphic, not cloth
fill< .5reads as a grid of strokes, not cloth
fill> .97gutters close; the weave flattens to a check
accent rate> .15accents stop being accents

FX-05

Graphite

Pencil hatching laid in strokes with tapered pressure. Graphite only lands on the tooth peaks the lead touches — and graphite is a metal: burnished, it gleams. Drag the light and the dark strokes turn silver.

Recipe

  1. Hatch strokes along an angle at a spacing; extra layers cross at an offset angle and only print where the value field asks for more tone.
  2. Each stroke is a wobbling polyline with pressure tapering at both ends, rasterized as AA capsules (lead width).
  3. Ink chain: pressure vs stock-height percentile — the lead touches peaks first; valleys stay white. Graphite is an opaque OKLab mix, not a film.
  4. Sheen: normals from the stock relief plus the graphite deposit's own burnish texture; Blinn specular toward the sheet light, gated by how much graphite is there.
  5. Light last: diffuse × stock shading, + specular.

Limits

ParamRangeWhat happens
spacing< 1.2 pxstrokes merge into flat gray
sheen> .8 at low lightstrokes read as wet ink, not graphite
lead> 1.6 pxreads as charcoal / marker

FX-06

Blind deboss

A mark with no ink. A die presses into the stock: the floor crushes the tooth flat, the walls take the light or the shadow, a lip rises at the edge. Move the light and the mark appears, flips, or disappears. Ink it to get letterpress.

Recipe

  1. Die = the ø co. brandmark, a word, or a ring seal, rasterized as an AA clip on the main thread (fonts).
  2. Plate profile from the signed distance to the die edge (exact distance transform): a crisp shoulder, a straight wall over the die softness, a flat floor; lip = a narrow ridge just outside the edge.
  3. Height (CSS px) = stock height × (1 − crush · plate) − depth · plate + lip — the tooth flattens on the floor.
  4. Light: Lambert from the combined height + a height-field shadow toward the sheet light (the wall on the light side falls in shadow).
  5. Optional ink on the floor (film), so blind → letterpress is one dial.

Limits

ParamRangeWhat happens

FX-07

Typewriter strike

Each glyph is a separate strike: its own pressure, a slight offset and rotation, sometimes only half the face lands. Ink passes through a woven ribbon, so letters carry the ribbon's weave; the type bar also dents the paper — visible under a low light.

Recipe

  1. Text in Courier Prime (a typewriter slab; bold below 15 px, as a light strike loses thin strokes), one strike per glyph on the main thread: pressure = ribbon life (exhausting along the page) × key variance; offset, rotation, an occasional dropped baseline; half-strikes fade top or bottom.
  2. Ribbon: a plain weave at the ribbon count — ink transfers through thread crossings, less through the gaps.
  3. Ink chain: pressure × ribbon vs stock-height percentile; ink squash pools film at the glyph edge.
  4. Impression: the strike dents the stock (blurred glyph × pressure); light from the combined height.
  5. Color: Beer–Lambert film.

Limits

FX-08

Hot foil

A metallic film, not a color. It conforms to the tooth, skips the deepest valleys, and its brightness is the light: a broad studio reflection plus tight glints off every facet. Holographic foil shifts hue with each facet's angle.

Recipe

  1. Die = the same shapes as FX-06; foil lands on the AA die × the stock: valleys below the starve height release no foil (pinholes), edge flash breaks the boundary at the film-split scale.
  2. Height = stock relief × (1 − crush) + foil grain (fine crumple) − a slight deboss; normals from it.
  3. Metal: a perspective viewer above the plate; the mirror vector per pixel samples a soft box at the sheet light (and a weak fill opposite), so the reflection sweeps across the foil; + tight Blinn glints; holo rotates the hue by facet orientation.
  4. Off-foil paper keeps its own light.

The sheet does not know what an effect draws. Copy this folder, replace set.js with your own effects and usages, run node build-sheet.mjs (bakes the static read, set.json and template.json), then register it in _shared/entries.js with section:'templates'.

Rules the sheet enforces by construction: one params object per effect and one sheet light; every length in CSS px; density dials change counts, not zoom; inks in OKLCH, chroma reduced at constant L/h when out of sRGB; marks print INTO a stock through one ink chain; light is applied once, last; masks sample at the mark, so marks are whole or absent.

fx.jsshared core · noise, 64² blue-noise rank (void-and-cluster), ease curves, OKLab/OKLCH + gamut, film + mix + overprint rules, randomized mask (coverage + signed distance), sheet light, Lambert shade, height-field shadow, cast shadow, capsule + dot rasters
set.jsthis set · stocks (paper, cloth), the ink chain, effects (params, recipe, limits, run) and usages — the only file a new set replaces
worker.jsrender worker · loads fx.js + set.js, renders one job off the main thread, caches stock fields
sheet.js · sheet.cssgeneric runtime · worker pool (latest job wins, ½-res drafts), stock coupling, light puck, rack, blocks, tabbed dials (limit zones hatched, default tick, type-in values, OKLCH tracks, ease graphs, five-rule mix strip), loupe, views, usage gallery
set.json · template.jsonmachine-readable spec of the set and of the contract
index.htmlbuild output · static read baked in
self.FXSET = {
  code:'T-04', title, short, set, premise, source,
  system:{ read, sharedCause:[…], passOrder:[…] },   // the material system, shown above the bar
  effects:[{
    id, code, name, sub, role,            // role: 'stock · paper', 'mark · pen' …
    recipe:[ 'step', … ],                 // numbered on the sheet
    limits:[ [param, range, 'what happens'], … ],
    params:[ { key, label, group, type, value, … } ],
      // group: density | dropoff | stock | relief | color | mixing | mask | seed
      // type:  range {min,max,step,unit,limits:[[lo,hi,why]]}
      //        select {options} · ease (value ['smooth',k])
      // ink:   FX.INK_PARAMS(prefix,label,L,C,h) → 3 OKLCH sliders
      // when:  { key:[values] } dims a param that does not apply
    stockOf(o) { return 'fx-03-…' },      // optional: the effect this one prints on → coupled redraws
    run(o, W, H, dpr, x) {                // W,H device px; lengths in o are CSS px; light = FX.LIGHT
      // x = { S: every effect's params, alb, clip, field }
      return { lin, alb, lf, ink, stock, mask, marks, markUnit };
    }
  }],
  usages:[{ id, title, sub, uses:[effect ids], aspect,
            overrides:{ [effectId]:{…} }, labels:[[a,b]],
            clips:{ name:(ctx2d, w, h) => draw },   // main thread (fonts), passed in as Float32
            run(P, W, H, dpr, x) { return effect.run(P(id), W, H, dpr, { S:x.S, clip:x.clips.name }); } }]
};
