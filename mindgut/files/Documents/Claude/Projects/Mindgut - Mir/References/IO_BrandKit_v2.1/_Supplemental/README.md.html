# The Impøssible Outcomes Company — Brand ToolKit

This folder is your one-stop brand system. It's built for both human designers and AI/LLM-powered creative workflows.

---

## Start here

Open **`IO_Brand_Guide_Toolkit.html`** in any browser. It's the complete interactive brand guide — live specimens, color swatches, gradient frameworks, expressive frameworks, slide templates, do's and don'ts, and the full logo system rendered inline. Everything else references it.

## Using this for LLM creative output

The toolkit is designed so you can hand `IO_Brand_Spec.md` (concise) or `IO_Brand_Spec_AI.md` (detailed) to any LLM (Claude, GPT, etc.) and get on-brand results — presentations, web layouts, social posts, copy.

**For best results:** paste `IO_Brand_Spec.md` into your system prompt or context window, then ask the LLM to create. For deeper integration patterns (RAG, chunking, multi-file retrieval), see `README_AI.md`.

**To validate:** run the 5 test prompts in `IO_Brand_Spec_AI_Validation.md` against your LLM. If it passes all five, it has internalized the brand correctly.

## Quick gotchas

1. It's Imp**ø**ssible, not Impossible. Always. (U+00F8, not the null set ∅)
2. Black and cream are the real brand colors. The bright accents cover ≤15% of any layout.
3. The brand has an equal-status light mode — warm cream `#F5F0E8` with black line-art. Use it.
4. The tagline is "But never impossible" — not "But never *is* impossible."
5. No raw stock photography. Every image gets a brand treatment.
