# IO Brand Kit — Quick Start Guide

**For Impøssible Outcomes team members using Claude or other AI tools.**

---

## What's In the Kit

- **IO_Brand_Guide_Toolkit.html** — The complete brand system. Open in any browser. Contains the full identity guide, slide templates, and quick-reference panels.
- **IO_Brand_Spec.md** — Machine-readable brand specification. Feed this to Claude, ChatGPT, or any LLM when you need on-brand outputs.
- This file — you're reading it.

## Using the Brand Guide

Open `IO_Brand_Guide_Toolkit.html` in Chrome, Safari, or Firefox. The sticky nav at the top lets you jump between sections. Everything is self-contained — no server, no dependencies, no internet required.

## Working with Claude

When starting a new project in Claude that requires brand-consistent output:

1. **Upload IO_Brand_Spec.md** at the start of your conversation.
2. **State what you need** — a presentation slide, a document, marketing copy, a social post.
3. **Reference the spec** — Claude will follow the color system, typography, voice guidelines, and naming conventions automatically.

### Common requests that work well:

- "Create a dark-mode slide with these three data points."
- "Write copy for our new service page. Follow the IO voice guidelines."
- "Generate an SVG graphic using the brand's prismatic gradient."
- "Draft an email signature for [name], [title]."

### Things to watch for:

- Make sure Claude uses **Impøssible** (with ø), not "Impossible."
- Default backgrounds should be Rich Black (#0A0A0A) or Warm Cream (#F5F0E8) — never pure white.
- Color accents should be ≤15% of the total surface area.
- The brand voice is declarative, concrete, short. Not corporate-speak.
