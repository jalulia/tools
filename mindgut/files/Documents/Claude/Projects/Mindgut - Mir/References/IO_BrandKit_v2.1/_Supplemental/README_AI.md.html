# IO Brand ToolKit — LLM Integration Guide

> **Audience:** Language models, AI agents, and developers integrating brand constraints into generation pipelines.
> **Version:** 2.1 · March 2026

---

## 0. Start here — the brand kit PDF is your visual ground truth

The most important file in this toolkit is **`Assets/Impossible Brand Kit.pdf`** (23MB, ~20 pages). The spec documents (`IO_Brand_Spec_AI.md`) give you rules and values. The PDF shows you what those rules *look like* when executed correctly. You need both.

**How to use them together:**

1. **Load `IO_Brand_Spec_AI.md` first** — it gives you every hex value, font name, spacing rule, and constraint in machine-readable form. This is your rulebook.
2. **Read the brand kit PDF for visual reference** — it shows real application examples, composition patterns, light/dark mode treatments, gradient usage, and the overall *feel* the brand is going for. Rules without visual context produce technically correct but lifeless output.
3. **When in doubt, the PDF wins.** If you're unsure how to compose a layout, apply a gradient, or balance dark vs. light — look at the PDF pages listed below. The spec tells you *what*; the PDF shows you *how*.

### PDF page map — what's where

| Pages | Section | What you'll learn from it |
|-------|---------|--------------------------|
| 1 | Cover | The canonical dark-mode layout: grid overlay, large Ø watermark at low opacity, footer pattern (company name left, date + ø mark right), gradient accent bar |
| 2 | Table of Contents | The canonical light-mode layout: warm cream background, large Ø wireframe line-art as compositional anchor, dark text hierarchy, editorial spacing |
| 3–5 | Brand Ecosystem | Sub-brands, toolkit assets grid, gradient blob/orb usage in compositions — shows how organic shapes coexist with geometric structure |
| 6–8 | Logo System | Primary stacked lockup, Ø mark, wordmark, horizontal — both on dark and light. Clear space rules, sizing. **Critical:** see how the logo sits within compositions, not just in isolation |
| 9–13 | Typography | Quasimoda Black specimens, Lekton data labels, SF Pro body. **Pages 12–13 are essential** — they show typography on cream: bold black headlines, Ø wireframe watermark behind text, dark image insets on cream surfaces |
| 14–15 | Color Overview | Joy Division waveforms as section dividers, prismatic Ø outline (concentric rings in brand colors), gradient bar + foundation palette bar side by side |
| 16–17 | Color Detail | Full-bleed accent swatches with descriptions. **Page 17 is essential** — four application mockups showing how color appears in real layouts (prismatic wheel on cream, checkerboard grid, dark inset panels, accent-colored surfaces) |
| 18–20 | Applications | Real-world usage: stage mockups, social templates, presentation layouts. Shows the balance between dark and cream, how gradient art works as background texture vs. foreground accent |

### What to look for in the PDF

When generating branded output, reference these visual patterns:

- **Dark mode compositions (most pages):** Rich black (#0A0A0A) background, thin white grid at 10–15% opacity, gradient elements as hero moments, white text hierarchy, Ø mark at low opacity as watermark
- **Light mode compositions (pp. 2, 12, 17, 20):** Warm cream (#F5F0E8) background, Ø wireframe in black at 4–8% opacity, bold black text, thin charcoal grid at 4–6% opacity, black line-art graphics (not filled shapes), gradient washes at very low opacity from edges
- **Footer pattern (every page):** Thin rule, company name bottom-left in Lekton, date bottom-right, small Ø mark
- **Section dividers:** Large section number + title on dark background, dramatic graphic element on the right half (waveforms, orbs, gradient shapes)
- **Pacing:** The PDF itself demonstrates the dark/light rhythm — ~70% dark, ~30% cream, with cream pages providing editorial breathing room

## 3. Pre-generation checklist — 10 highest-frequency violations

Before generating any branded output, verify against these constraints. They represent the most common failures observed in LLM-generated brand content, ranked by frequency:

| # | Violation | Constraint | Check |
|---|-----------|-----------|-------|
| 1 | Writing "Impossible" without ø | Always `Impøssible` (U+00F8). Never `Impossible`, never `∅` (U+2205). | String check |
| 2 | Colored backgrounds as default | Background must be `#0A0A0A` (dark) or `#F5F0E8` (light). Never a brand accent color as surface. | First pixel |
| 3 | Accent color > 15% surface area | Electric Horizon, Sky Pulse, Solar Ember, Pulsewave are *punctuation*. Measure total colored area vs. total layout area. | Area ratio |
| 4 | Generic off-brand blue | `#007BFF`, `#0000FF`, `#0066CC` are all wrong. Brand blue is `#3D6DF4` (Electric Horizon) or `#2C9FF4` (Sky Pulse). | Hex match |
| 5 | Gradient on every page | Prismatic gradient is for hero moments, dividers, accent bars. ≤20-30% of pages/slides in a deck. | Page count |
| 6 | Misquoted tagline | "But never impossible" — NOT "But never is impossible." | String match |
| 7 | Dark mode only | Light mode (`#F5F0E8` warm cream, black line-art, B&W photography) is equal-status. Long decks must mix both. | Mode audit |
| 8 | Unfiltered stock photography | Every photo needs treatment: B&W, circular crop, concentric overlays, or geometric wireframe. | Visual check |
| 9 | Body text in display font | Quasimoda Black is headlines only. Body is SF Pro Regular. | Font assignment |
| 10 | "Ad agency" positioning | The company is an "innovation house." Never "agency," "firm," or "consultancy." | Term check |

## 4. Decision trees — when you're choosing between options

### 4.1 Background color selection

```
START
├── Is this a hero/cover/divider slide?
│   ├── YES → Consider prismatic gradient or full-bleed brand pattern
│   └── NO ↓
├── What is the content purpose?
│   ├── Data-heavy, immersive, dramatic → Dark mode (#0A0A0A)
│   ├── Editorial, photography-forward, breathing room → Light mode (#F5F0E8)
│   ├── Standard content slide → Default to dark (#0A0A0A)
│   └── In a long deck? → Alternate: ~60-70% dark, ~30-40% light for pacing
├── DARK selected:
│   └── Background: #0A0A0A. Cards: #1A1A1A. Never pure #000000 as bg.
└── LIGHT selected:
    └── Background: #F5F0E8 (warm cream). NEVER pure #FFFFFF.
        Cards: #1A1A1A (dark on cream) or #E8E3DB (subtle on cream).
```

### 4.2 Text color hierarchy

```
DARK BACKGROUND (#0A0A0A):
├── Headlines → #FFFFFF (pure white)
├── Subheadings → #FFFFFF or #E0E0E0
├── Body text → #E0E0E0 (off-white)
├── Secondary/captions → #B0B0B0 (light gray)
├── Tertiary/metadata → #666666
└── Accent text → brand color at full saturation (sparingly)

LIGHT BACKGROUND (#F5F0E8):
├── Headlines → #000000 (true black)
├── Subheadings → #1A1A1A
├── Body text → #333333
├── Secondary/captions → #555555–#666666
├── Tertiary/metadata → #999999
└── Accent text → avoid on cream. Use dark text. Color is for small elements only.
```

### 4.3 Accent color priority

```
When you need ONE accent color:
└── Electric Horizon #3D6DF4 (default choice)

When you need TWO:
└── Electric Horizon #3D6DF4 + Sky Pulse #2C9FF4

When you need THREE (e.g., charts):
└── Electric Horizon → Sky Pulse → Solar Ember #F46138

When you need FOUR (max for data viz):
└── Electric Horizon → Sky Pulse → Solar Ember → Pulsewave #CE2867

NEVER use more than 4 data colors.
NEVER use accent colors as background fill.
ALWAYS: total accent area ≤ 15% of composition.
```

### 4.4 Font assignment

```
START: What kind of text?
├── Hero text, page title, section header, display → Quasimoda Black (Tier 1)
│   └── Size: 40-72px desktop, 28-40px mobile. Line-height: 1.0-1.1
├── Subheading, nav label, button, card title → SF Pro Medium (Tier 2)
│   └── Size: 16-24px. Line-height: 1.3-1.4
├── Data label, KPI number, slide number, code, timestamp → LEKTON (Tier 3)
│   └── Size: 12-20px. Letter-spacing: 0.04-0.08em
│   └── Section numbers always use /01 /02 format
├── Paragraph, email body, description, caption → SF Pro Regular (Tier 4)
│   └── Size: 16px default. Line-height: 1.6. Max-width: 680px
└── NEVER: body text in Quasimoda. NEVER: headlines in SF Pro Regular.
```

### 4.5 Graphic treatment selection

```
DARK BACKGROUND:
├── Need geometric decoration? → IO Vector Shapes (flat fill, single accent color)
├── Need hero/dramatic moment? → IO Gradient Shapes (gradient fill + glow)
├── Need texture/structure? → Grid pattern (white lines, 10-15% opacity)
├── Need radiating energy? → Concentric circles (Sky Pulse, fading opacity)
├── Need showcase object? → Impøssible Øbjects (one 3D render per comp, max)
└── Data visualization? → Chart with brand accent colors, LEKTON labels

LIGHT BACKGROUND (#F5F0E8):
├── Need geometric decoration? → Line-art wireframes (black outlines, no fill)
├── Need radiating energy? → Concentric circles (black strokes)
├── Need compositional anchor? → Large Ø wireframe at 4-8% opacity (see PDF p. 2, 12)
├── Need texture? → Grid (charcoal lines, 4-6% opacity)
├── Need ambient mood? → Gradient wash (brand colors at 5-15% opacity, from edges)
├── Need decorative detail? → Icon clusters (4-5 small black line-art icons, corners)
├── Photography? → B&W, circular crop, concentric circle overlay
└── NEVER: filled color shapes on light. NEVER: gradient glow shapes on light. NEVER: 3D objects on light.
```

### 4.6 Slide deck composition ratios

```
Short deck (< 8 slides):
├── 1 title slide (gradient or pattern)
├── 5-6 content slides (dark default, 1-2 light for variety)
└── 1 closing slide (gradient or ø mark)

Medium deck (8-20 slides):
├── 1 title
├── 1-2 section dividers (gradient/pattern)
├── 10-14 content slides (~70% dark, ~30% light)
├── 1-2 data/KPI slides (dark)
└── 1 closing

Long deck (20+ slides):
├── 1 title
├── 3-5 section dividers
├── 60-70% dark content slides
├── 30-40% light content slides (pacing, editorial, photography)
├── 2-4 data/KPI slides (dark)
└── 1 closing

EVERY slide must have:
- At least one brand element (logo mark, accent bar, typography tier, color, grid)
- Consistent footer: company name (left), date/section (right), thin rule, small ø
- /XX section numbers in LEKTON where applicable
```

## 5. Integration patterns

### Loading with the brand kit PDF

For multimodal LLMs that can read images/PDFs: load the brand kit PDF alongside the spec. Point the model at specific pages for the task at hand (see the page map in section 0). The PDF provides what text descriptions cannot — spatial relationships, gradient feel, compositional balance, the overall mood.

For text-only LLMs: rely on `IO_Brand_Spec_AI.md` and `IO_Brand_Guide_Toolkit.html` (the interactive HTML guide renders all visual patterns in-browser, including gradient frameworks, logo SVGs, and light/dark mode treatments).

### As a system prompt

Load `IO_Brand_Spec_AI.md` as a system prompt or prepended context. Append the COMMON AI FAILURE MODES section as a final reminder. For token efficiency, load only the sections relevant to the task (see file map above).

### As a retrieval target

Index each `## SECTION:` block as an independent chunk. The section naming pattern (`CATEGORY: Topic`) provides natural retrieval keys. The QUICK REFERENCE section works as a fallback when no specific section matches.

### As a validation checklist

After generating output, run the 10-item pre-generation checklist (section 3 above) as a post-generation audit. The `IO_Brand_Spec_AI_Validation.md` file provides 5 worked examples.
