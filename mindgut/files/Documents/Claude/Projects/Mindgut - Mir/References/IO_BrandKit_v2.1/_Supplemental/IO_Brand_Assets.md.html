## /08 — FILE NAMING CONVENTION

**Observed pattern:** `IO_branding_[sequence]_v[version]`

**Recommended convention for new assets:**
```
IO_[asset-type]_[descriptor]_v[version].[ext]

Examples:
IO_logo_primary-white_v01.svg
IO_logo_mark-blue_v01.png
IO_gradient_prismatic-horizontal_v01.css
IO_template_slide-title_v01.pptx
IO_icon_primary-set_v01.svg
```
