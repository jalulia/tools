# Artifact Brief: Scinote → Sample Machine

## What
Convert `artifacts/scinote.html` (48-cell generative grid) into an audio sampling machine. Each cell becomes a sample pad — click to trigger, hold to preview, right-click to assign/edit.

## Reference
- **Massive SFX Log** (sfx-spark-organizer.lovable.app) — Julia's full SFX organizer with groups, inspector panel, waveform preview, trim start/end, versioning, export ZIP. The sample machine should be a **drastically simpler** version of this — think MPC pad meets specimen grid.
- **Screenshot reference**: Inspector panel shows waveform preview, play/skip controls, Trim Start (ms) / Trim End (ms) inputs, original filename, event token, version, group dropdown, notes field.

## Architecture
Keep the existing scinote shell: 8×6 grid, dark bg (#0A0A0A), IO Brand Kit colors, Lekton monospace font, cell hover influence.

### Core Flow
1. **Empty state**: Each cell shows its generative viz (current behavior) — cells are "unloaded"
2. **Load a sample**: Click empty cell → opens a mini panel:
   - Upload audio (wav/mp3/ogg via file input)
   - Record audio (MediaRecorder API, mic input)
   - Paste from library (if samples already imported)
3. **Loaded state**: Cell shows a mini waveform thumbnail (canvas-drawn) + short label. Cell border color = IO brand palette (rotate through EH/SE/PW/SP based on index).
4. **Trigger**: Click loaded cell → plays the sample (clipped region). Visual flash on trigger.
5. **Edit/Clip**: Right-click or long-press loaded cell → opens Inspector overlay:
   - Waveform display (full audio, zoomable)
   - Trim Start / Trim End markers (draggable on waveform, or ms input fields)
   - Play preview (plays only clipped region)
   - Name field (auto-populated from filename, editable)
   - Remove button (clears cell)
6. **Library**: Side drawer or bottom panel listing all imported audio files (not yet assigned to cells). Drag from library to cell to assign.

### Minimal Library
- Import multiple files at once (multi-file input or drag-drop zone)
- Each entry: filename, duration, tiny waveform, play button
- Drag to a cell to assign
- Delete from library
- Persists in localStorage (store as base64 or just re-upload per session)

### Audio Engine
- Web Audio API: `AudioContext`, `AudioBufferSourceNode`
- Decode uploaded files via `decodeAudioData()`
- Clip playback: `source.start(0, trimStartSec, trimEndSec - trimStartSec)`
- Record: `navigator.mediaDevices.getUserMedia({audio:true})` → `MediaRecorder` → Blob → decode
- No effects chain needed (pure sample playback)

### Waveform Drawing
- Draw `AudioBuffer.getChannelData(0)` downsampled to cell width
- Full waveform in inspector (zoomable via scroll)
- Trim region shown as highlighted overlay on waveform
- Use canvas for all waveform rendering (consistent with existing scinote approach)

### Visual Design
- **Empty cell**: Current generative viz, dimmed. Label "drop audio" at low opacity.
- **Loaded cell**: Mini waveform fills cell, IO brand border glow, name label bottom-left (8px Lekton), duration top-right.
- **Playing cell**: Brief flash (white border pulse, fast decay), waveform highlight sweeps across during playback.
- **Inspector overlay**: Dark panel (charcoal #1A1A1A), slides in from right or appears as modal. Waveform takes top half, controls below. Matches the Massive SFX inspector layout but simplified.

### What NOT to Build (keep it simple)
- No groups/categories sidebar (just the 48-cell grid)
- No export ZIP
- No auto-versioning
- No bulk edit
- No search
- No event tokens
- No complex routing

### Data Model
```javascript
// Per cell
{
  id: 0-47,
  audioBuffer: AudioBuffer | null,
  fileName: string,
  trimStart: number (ms),
  trimEnd: number (ms),
  name: string,
  color: string (IO brand color)
}

// Library
[
  { fileName, audioBuffer, duration, waveformData }
]
```

### Keyboard Shortcuts (stretch)
- Number keys 1-8 trigger row 1 cells
- Q-I trigger row 2
- A-K trigger row 3
- Space = stop all
