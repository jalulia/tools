## /01 — VISUAL REFERENCES: What Julia Is Drawn To

Reviewed ~40 images from the References folder (118 total). The collection speaks a very specific visual language. Here's how it breaks down:

### Style Families

**A. Scientific Notation as Art**
The largest category. Hand-drawn colored-dot compositions on graph paper (looks like Iannis Xenakis or early computational music notation). Frequency/waveform charts (white on black, showing harmonics 200–8000Hz). Magnetic field line drawings. Circuit schematics used as typography. Fourier series animations. Harmonic overtone diagrams with colored curves.
*The signal: science that was never trying to be beautiful, but is.*

**B. Retro-Scientific / Terminal HUD**
Concentric circle overlays with timecodes and monospaced readouts ("INTERNAL.SYSTEM / SYS.ORL LIVE"). Oscilloscope-style waveform animations (orange/red sine waves on black CRT). The aesthetic of instruments — not interfaces.
*The signal: the beauty of measurement itself.*

**C. Topological / Field Distortion**
Gravitational lensing grids (a sphere warping a Cartesian mesh). Orbital trace drawings (dotted line spheres, Lissajous-like paths). Grid deformation as visual metaphor for force. The REBOUND n-body banner.
*The signal: when math bends space, and you can see it.*

**D. Data Visualization (Information Design)**
Dark-background multivariate waveform charts (TV viewing data as layered colored curves). Baseball salary scatter plots with regression lines. 3D point-cloud particle data (Dataism aesthetic). Dark-mode dashboards with topographic maps. ALMA galaxy velocity maps (rainbow contour fields on black).
*The signal: real data, rendered with rigor and taste.*

**E. Generative Geometry / Code Art**
Dot-matrix spiral patterns (rainbow on black). Connected-node network graphs. Wireframe spheres with glow. The geometric primitive sampler sheets (stars, waves, grids, orbs — white on black and white on white).
*The signal: the visual vocabulary of computational form.*

**F. Emergence / Cellular Systems**
Grid panels showing pattern evolution through phases (host → attraction → adoption → dominance). Text-as-particle fields (letters dissolving into connected node graphs). Dot-density patterns showing system state transitions.
*The signal: simple rules producing complex visible behavior.*

**G. Whimsy + Humanity**
Aerial-view illustration of people on graph paper with connections drawn. The "lil-mirs-yous" image. Playful error page (404 with dissolving typography). Blue monochrome circuit-as-typography page.
*The signal: delight is not the enemy of rigor.*

### The Through-Line

Julia is drawn to **the place where rigorous science becomes visually beautiful without trying** — not decoration applied to data, but the inherent aesthetic of mathematical/physical structures rendered with care. Strong preferences:

- Precision and restraint over flashiness
- Dark backgrounds with luminous, spare elements
- Wireframe and line-art over filled/solid shapes
- Systems that reveal their own logic through form
- Both analog and digital aesthetics coexisting (hand-drawn notation next to terminal HUDs)
- The "beautiful accident" of science — galaxy velocity maps, field distortions, harmonic patterns
- Things that reward close inspection

### What's NOT in the collection

- Decorative generative art (the "pretty swirls" genre)
- Heavy 3D renders with PBR materials
- Gradient-heavy modern SaaS aesthetic
- Stock-style data visualization (pie charts, bar charts)
- Anything that looks like it was made to be impressive rather than true

## /03 — SKILL ZIPS: Assessment & Recommendations

### Strongly Recommend Installing

**1. `threejs`** (v2.0.0)
Full Three.js development skill with progressive learning path (fundamentals → advanced shaders → WebGPU). 17 reference docs covering geometry, materials, post-processing, physics. Essential for any 3D visualization work — orbital mechanics, lattice geometry, field distortions.
*Why:* Multiple reference images demand 3D (wireframe spheres, field distortions, particle systems). The helix-visualizer already uses canvas — Three.js is the natural next dimension.

**2. `threejs-shaders`**
GLSL shader writing for Three.js — ShaderMaterial, uniforms, custom vertex/fragment effects. This is how you get the luminous, precise, scientific-instrument aesthetic (glow, field lines, custom color mapping).
*Why:* The terminal HUD aesthetic, the concentric ring glow, the waveform animations — all shader territory.

**3. `claude-d3js-skill`**
D3.js visualization guidance with references on color schemes, scales, and patterns. For 2D data-driven visualization — network graphs, force layouts, chord diagrams, geographic projections.
*Why:* Several reference images are pure information design (the TV viewing waveforms, baseball scatter plots, connected node graphs). D3 is the right tool for data → visual.

**4. `creative-thinking-for-research`**
Cognitive science frameworks for creative ideation — bisociation, problem reformulation, analogical reasoning, constraint manipulation. Not a coding skill — a thinking skill.
*Why:* The brief says "go wide and deep, then curate." This skill provides the structured divergent thinking needed for the "go wide" phase. Combinatorial creativity (Framework 1) is literally how you'd cross PFD concepts with visualization techniques.

### Worth Installing (Secondary)

**5. `epic-design`**
Cinematic 2.5D web design — scroll storytelling, parallax depth, text animations. 45+ techniques. No WebGL required.
*Why:* If the gallery site itself should feel like an experience (not just a grid of thumbnails), this skill builds that. But it's for the site shell, not the visualizations themselves.

**6. `visualization-expert`**
Chart selection and data communication guidance. Lightweight — more of a reference card than a deep skill.
*Why:* Useful as a quick-reference overlay, but less essential than the others.

### Skip

**7. `scientific-schematics`**
Uses Nano Banana Pro AI (external API via OpenRouter) for diagram generation with Gemini review. Generates static PNGs from text descriptions.
*Why not:* Julia's references are about *interactive, code-generated* visualizations — not AI-generated static diagrams. The aesthetic is "code that produces beauty," not "AI that approximates science." This skill solves a different problem.

## /04 — BRAND SYSTEM NOTES (IO Brand Kit v2.1)

The brand system is well-documented and already internalized in the helix-visualizer. Key points for visualization work:

- **Dark mode is primary.** Rich Black #0A0A0A, Charcoal #1A1A1A cards. Light mode is Warm Cream #F5F0E8.
- **Accent triad (constant):** Electric Horizon #3D6DF4, Solar Ember #F46138, Pulsewave #CE2867, Sky Pulse #2C9FF4
- **Accents are punctuation, not paint.** ≤15% surface area. This aligns perfectly with the reference aesthetic — luminous elements on dark fields.
- **Typography:** Montserrat 900 / Inter / Lekton mono. Section numbers in Lekton `/01` format.
- **The Ø:** Not decorative — conceptual core. Wireframe at low opacity as compositional anchor.
- **Gradient bar:** 3-4px accent stripe only. Never as background.
- **Graphic vocabulary:** Concentric circles, connected nodes, data waveforms, grid textures — all already present in Julia's reference images.
- **The brand can flex.** The showcase examples demonstrate range from editorial to data-dense to immersive.

The PFD color mapping (147=warm/structure, 258=neutral/relation, 369=cool/derivation) maps naturally onto the IO accent system (Solar Ember → Electric Horizon → Pulsewave).

## /07 — DECISIONS LOCKED IN

**What this is:** A fast-iteration workbench for Mindgut/PFD visualizations. Not a portfolio. Not a public explainer. A tool for vibe coding and curation.

**Repo:** github.com/jalulia/mir-gallery
**Pages URL:** jalulia.github.io/mir-gallery
**Branch:** main, serving from root

**Two-tab structure:**

**Tab 1: References** — Browsable, filterable grid of visual reference images (the 118+ files from the References folder, plus collected URLs). Mood board energy. Taggable, sortable, annotatable. This is the taste library.

**Tab 2: Artifacts** — The actual visualization pieces being built. Each is a standalone sketch (JSX, HTML, p5) mounted in an iframe. Cards show live preview or thumbnail, title, description, status (WIP/draft/stable), tags. Drop a file in, add a metadata entry, it appears.

**Workflow:** Describe a viz idea in chat → Claude builds it → drop file into artifacts/ → gallery picks it up and renders it.

**Design language:** IO Brand Kit v2.1 (Rich Black #0A0A0A, Warm Cream #F5F0E8, accent triad, Montserrat/Inter/Lekton). The gallery shell itself should be restrained — the visualizations are the point, not the frame.

**Skills to install (for future viz building sessions):**
1. `threejs` — 3D lattice/field/orbital work
2. `threejs-shaders` — luminous scientific-instrument aesthetic
3. `claude-d3js-skill` — 2D data-driven pieces
4. `creative-thinking-for-research` — structured creative ideation

**Next step:** Build the gallery shell (index.html with two-tab UI, card grid, filtering, iframe mounting) and push to the repo.
