## Phase 3: UI/UX CLEANUP `[ ]`
Fix the tooltip/hover experience across all views.

**Problems identified (from Julia's screenshots + feedback):**
- Hover targets too small on dense areas
- Tooltip disappears too fast / hard to read on hover
- Dark-on-dark contrast makes labels invisible
- No way to "pin" a strand for sustained inspection
- Info panel shows metadata but not enough context
- Legend monospace but low contrast

**Solutions:**
- Click-to-pin strand detail panel (bottom-left, persistent)
- 7-word text preview + "see more" click reveal (CONTENT POLICY)
- Viewport-clamped tooltip positioning (never off-screen)
- Larger hit targets (min 8px radius, 12px in dense zones)
- Monospace typography with proper weight hierarchy
- High-contrast legend with clear type/coset labels
- Panel backgrounds with slight blur/transparency for depth
- Smooth fade transitions on hover/click state changes
