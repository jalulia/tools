## Steps

### 1. Copy images
```bash
cp ~/Documents/Claude/Projects/Mindgut\ -\ Mir/Visualizations/References/* \
   ~/Documents/Claude/Projects/Mindgut\ -\ Mir/mir-gallery/references/
```

Skip `___pdf.pdf` — it's not an image reference. Also skip the `_ContactSheet-*.jpg` files (6 of them) — those are overview contact sheets, not individual references. That leaves ~119 actual reference images.

### 2. View each image and categorize

Each image needs a short **name** (2–5 words describing what it depicts) and **tags** from this vocabulary:

| Tag | Meaning |
|-----|---------|
| `notation` | Scientific notation, hand-drawn dots, frequency charts, musical scores, circuit diagrams |
| `terminal` | Retro HUD, oscilloscope, CRT, monospaced readouts, instrument panels |
| `topology` | Grid distortion, gravitational lensing, field lines, orbital traces, mesh warping |
| `dataviz` | Charts, scatter plots, dashboards, heatmaps, contour maps, data-driven |
| `generative` | Algorithmic/code art, dot-matrix, wireframe geometry, procedural patterns |
| `emergence` | Cellular automata, state evolution, phase transitions, pattern formation |
| `whimsy` | Playful, human figures, humor, warmth, illustration |
| `waveform` | Sine waves, harmonics, frequency spectra, oscillation |
| `orbital` | Orbits, trajectories, n-body, gravitational paths |
| `grid` | Grid structures, lattices, mesh, graph paper |
| `particles` | Point clouds, particle systems, dot fields, swarms |
| `network` | Node-link graphs, connected networks, force-directed layouts |
| `schematic` | Diagrams, blueprints, technical drawings, flowcharts |
| `color` | Strong color use as a defining feature |

Assign 2–4 tags per image. Lean toward precision over completeness.

### 3. Update index.html REFERENCES array

The array lives at approximately line 548 in `index.html`. Currently:
```js
const REFERENCES = [
  // Example entry — replace/extend with your actual references:
  // { file: "references/010174be7b366ba8caafae676b0c12f5.jpg", tags: ["schematics", "notation"], name: "Scientific primitives sampler" },
];
```

Replace with actual entries:
```js
const REFERENCES = [
  { file: "references/010174be7b366ba8caafae676b0c12f5.jpg", name: "scientific notation grid", tags: ["notation", "schematic", "grid"] },
  { file: "references/099dfa3bdd4c86f62dab8750f2f761b8.jpg", name: "oscilloscope hud display", tags: ["terminal", "waveform"] },
  // ... one entry per image
];
```

### 4. Git commit and push
```bash
cd ~/Documents/Claude/Projects/Mindgut\ -\ Mir/mir-gallery
git add references/ index.html
git commit -m "Add 119 categorized reference images to gallery"
git push origin main
```

### 5. Verify
Wait ~60s for GitHub Pages rebuild, then check `https://jalulia.github.io/mir-gallery/` — the References tab should show all images in a filterable grid.
