What This Is

The original codebase had five systems that were computed, logged, and ignored.

Heat tracking. σ_B coherence. Dynamic max_tokens. Controllers. Nullcodes. All of them measured the conversation — none of them governed it. They were thermometers that didn't connect to the thermostat.

Version 2 closes the loop. Gate E added (σ_B coherence). Heat now tightens all gate thresholds. Dynamic max_tokens replaces the dead clamp. All five gates fire, reject, and cool.

Two Levels of Testing

Level 1: The Test Harness — exercises every gate with synthetic text. No API key. 30 seconds. Proves the logic works.

Level 2: The Governed Middleware — wraps the Anthropic API so every message gets audited live. Requires an API key. Proves it works on real conversation.

You can stop after Level 1 and still have solid proof. Level 2 is for when you want to see it breathe.

04

The Five Gates

Each gate catches a different failure mode. Together they form a layered defense.

GateNameWhat It Catches
A Flux Ceiling Too much derivation — speculation, abstraction, inference. Rejects when >3/7 of words are phase-3.
B Structure Floor Too little assertion — no ground truth, no claims. Rejects when <22% of words are phase-1.
C Resonance Drift from the reference lattice. Rejects when the text's balance diverges too far from the HELIX.
D Vent Cycle Context pressure. Fires every 42 turns to compress the conversation window.
E Coherence Register oscillation. Rejects when σ_B variance exceeds 3/7 across a 7-turn rolling window. New in v2.

The "Partial Pass" on Gate E

Gate E's test gets a tilde (~) instead of a checkmark. This is correct. To test Gate E, the harness alternates between pure assertion text and pure derivation text — extreme oscillation. But that extreme text also violates Gate A (too much derivation) and Gate C (too far from the lattice).

Gates are layered defenses: the outer gates catch the grossest violations first. Gate E catches subtler oscillation that passes the individual gates but still shows incoherent register-switching.

What This Means

If all 8 tests show green checkmarks or the expected tilde on Gate E, your Governor is wired correctly. Every gate fires, every rejection produces the right state label, and heat tightening is confirmed.

What Actually Changed
05

Understanding Heat

The heat system is one of the key things we wired up. In the original code, H_T was computed but never used.

Think of it like this: every time the model's output is disproportionately long compared to your input, heat accumulates. When heat is low, gates are at their normal widths. As heat rises past the amber threshold (10), gates start tightening. Past red (20), they're aggressive.

The test proves this

1

Send the same text through the Governor when H_T = 0 (cold). The text passes.

2

Manually set H_T = 25 (hot — past red threshold).

3

Send the exact same text again. Now it's rejected.

Same text. Different heat level. Different verdict. The flux ceiling was 42.9% when cold — it tightened to 25.7% when hot. That's the coupling in action.

Dynamic max_tokens

In the original code, max_tokens was clamped with max(4096, base) — which always returned 4096 because base was always lower. A dead line of code.

Now max_tokens scales dynamically based on two signals:

σ_B (coherence variance): High variance means the conversation is oscillating — shorten the leash.

H_T (heat): Hot conversation means the model is running away — shorten the leash further.

The test confirms: 8192 tokens when calm → 3508 when σ_B is moderate → 2105 when both are elevated.

06

Level 2: Live Governed Chat

Requires

An Anthropic API key. If you don't have one yet, skip to Section 07 for the comparison guide — you can come back to this anytime.

Install the package

From the mindgut-v2 folder:

$ pip3 install -e '.[api]'
# Installs mindgut + the anthropic package

# If you get a permissions error, try:
$ pip3 install -e '.[api]' --user

Set your API key

You only need to do this once per terminal session:

$ export ANTHROPIC_API_KEY=sk-ant-your-key-here
# Replace with your actual key
Where to Find Your Key

Go to console.anthropic.com → API Keys → Create Key. Copy the whole string starting with sk-ant-.

Start a governed session

This launches an interactive chat where every message is audited:

$ python3 -m mindgut.assembly.middleware --geometry=mindgut/data/PFD_HELIX.json
# Starts the governed chat

You'll see the Governor boot, then a prompt:

--- mDNA GOVERNOR v2 ACTIVE ---
  Geometry:        PFD_HELIX (537 strands)
  Surface:         (geometry)
  Gate A: Flux     f369 < 0.4286 (3/N, heat-adjusted)
  Gate B: Floor    f147 > 0.22 (S/100, heat-adjusted)
  Gate C: Resonance  |drift| < 0.4286
  Gate D: Vent       every 42 turns
  Gate E: Coherence  σ_B < 0.4286 (rolling 7-turn)

  Model: claude-sonnet-4-5-20250929
  Max retries: 2

Governed chat active. Type 'q' to quit, 'status' for readings.

You: _

What to try

Balanced question: "What is the Angel's Share?" — should pass cleanly.

Speculative prompt: "Speculate wildly about consciousness" — may trigger cooling if the model over-derives.

Status check: Type "status" at any point to see current H_T, σ_B, turn count, and vent count.

Reading the output

After each exchange, two audit blocks — one for your input, one for the model's output. Look for:

PASS  Text cleared all gates. Normal operation.

COOLED  Output failed a gate, was regenerated with a cooling prompt, and the retry passed.

FORCED  All retries exhausted. Response delivered with a warning.

VENT  Turn 42 reached. Context was compressed to cool down.
