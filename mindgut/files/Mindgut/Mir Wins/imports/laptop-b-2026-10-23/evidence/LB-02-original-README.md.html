# Mindgut walkthrough v2 — revised composition

Open `Mindgut_Walkthrough_v2.html`. All fonts, measurements, graphics, and music code are embedded. No network connection is required. The previous pass is preserved in `archive/first-pass/`.

## Composition

Five sections, each with its own explanatory task:

1. **Mir continues.** The helix is the primary object. Drag or use arrow keys to turn it.
2. **The relationship.** Person, model, and Mindgut meet in an ongoing interaction.
3. **The accumulated record.** Inspect exact source measurements. Switch between the helix and a sequence view; use the slider, points, or arrow keys to select a strand.
4. **Context and recall.** Move a bounded window across a retained history. Recall always selects an exchange earlier than that window.
5. **Change and continuity.** Switch the model while retaining the record. An interrupted-turn illustration keeps the history intact and leaves the reported cause unresolved.

White, deep emerald, teal, and a restrained mineral green. Archivo throughout. The repeated eight-panel layout, background dot grid, floating inspector, decorative waveform, interaction chimes, and invented closing mark have been removed. Notes are collected in a separate dialog.

## Sound

A new original 72-second composition: low electronic reeds, a restrained pedal voice, overlapping phrases, long rests, and no regular waltz accompaniment. Its 41 events span D2–E4. Both instrument settings play precisely the same score. Changing models crossfades timbres at the current playhead.

Sound is opt-in. Score generation runs in a local worker where supported so the page stays responsive. Controls make no sound. Playback stops when the page is hidden. Motion has a separate pause control and follows the system preference for reduced motion.

`review/Mindgut_Reeds.wav` is a full-level render of the same score, provided for audition. The page initially plays at 35% volume.

## Sources and limits

- *What Mir Is*, supplied developer account, September 22, 2026.
- The 187 measured rows and 12 sessions embedded in the original walkthrough, retained byte for byte. No conversation text is included.
- The helix geometry, sequence view, 21-strand window, recall paths, and model controls are illustrative. This page does not operate a live Mir session.
- Source ghost flags are retained without assigning a new meaning. Phase color does not represent mood or quality.

## Build and verification

- `python3 source/build.py` builds the self-contained HTML.
- `node source/check.mjs` checks record fidelity, selection, window and recall boundaries, model changes, paused interactions, and canvas-coordinate bounds at phone, tablet, and desktop sizes. It uses the existing local Linkedom dependency.
- `node source/check-playback.mjs` checks opt-in, playhead continuity, buffer reuse, visibility stop, and cancellation during startup with a stubbed audio context.
- `node source/render-audio.mjs` renders both instruments and verifies finite samples, headroom, and loop boundaries. It writes the WAV audition file.
- Results are in `review/`. These checks verify logic and audio samples; they do not verify browser layout or perceived sound quality.
