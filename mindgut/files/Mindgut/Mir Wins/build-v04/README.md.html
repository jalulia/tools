# Mir Study V04 source

1. `python3 create_interface.py` creates the shared interface fragment from the unchanged `components/ui-bundle.json` snapshot, `polish.css`, and supplied logo assets.
2. `python3 build_hub.py` derives V04 from preserved V03, removes Moments and old interface studies, updates the index and statement, and produces the standalone LB-01 V02.

The source bundle is Docs 09's original CSS, DOM, local demo handlers, three coded viewer documents, and bundled Three.js/OrbitControls. No live API is connected. Changes are CSS surface treatment, light default, sidebar starting position, initial theme ARIA state and routing existing HELIX links to the corresponding source viewer. Product control structure is retained. No book/reading desk proposal is included.

`content.json` holds 22 work families. `statement.json` is the new draft. Fonts are embedded; Archivo's width axis is pinned out of the font binary, and the product retains static normal-width Roboto. `interface.html/css/js` are generated outputs used by the hub and standalone. The requested board aside uses a copy with a scoped font name and adjusted local link.

No browser-rendered QA is claimed for this version. See the review files for scope and the blocked local preview.
