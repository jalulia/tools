# Mir Study V05

Run `python3 build_hub.py` to generate the current master `Mir_Study_V05.html` and update the compatibility entry `Mir_Study_V04.html`. The original V04 source is preserved in `_archive/2026-10-23-v05-before-curation/`; this builder reads that snapshot, not the compatibility entry.

`content.json` holds the 18 work families and their categories. All is the default; Mindgut has 14 entries, Pop has three, Other has the independent Hapax badge. POP is ordered last, boards first. Context cannot render links; current alternate formats appear as explicit main actions. Superseded versions are plain deprecation notes.

Statement and Interface study are byte-preserved from V04. Rendering was not repeated; source, category, link and syntax checks are in `review/Curation_Checks_V05.json`.
