# Mindgut / Mir — Product Design (UI/UX) Report
Worker a10 (product_ux_2). Sources: BRIEF.md, What Mir Is, Oct 19 transcript, Slack OCR Apr 30–Oct 19. All quotes are verbatim from those files unless marked (paraphrase).

## UX audit — 10 problems, ranked

Ranked by (cost of the failure) × (how many of the team hit it). Each: evidence, then the fix in one line.

1. **Work can be lost on update or at the first-run dialog.**
   Evidence: Colin, Slack: "i just downloaded the new mindgut, woo! but i lost all the work i did yesterday, boo!" Chris, Slack: "if you choose 'START' at the load screen of the desktop client, it means you're starting a brand new helix."
   Fix: "Start new" never sits next to "Continue"; the app always opens the most recent HELIX, and creating a new one is a deliberate second screen with the current strand count shown.

2. **Desktop ⇄ browser sync is a mental model nobody holds.**
   Evidence: Julia, Oct 19: "when we switched to desktop there was just like a series of updates and syncing didn't work and so I kind of fell out of using it." Chris, Slack: "When you log back in online it will kick you out of desktop and vice versa."
   Fix: one account, one HELIX, both clients show the same strand count and a "last synced 2m ago · 4,199 strands" line; the kick-out becomes a visible handoff ("Browser took the session at 3:41 PM. Take it back?").

3. **No search in the HELIX.**
   Evidence: Brittany, Oct 19: "it was like several hundred strands back and there's no search feature."
   Fix: ⌘K search over strand text, date, phase, and model, with results as strand cards that can be pulled into context.

4. **The 2,000-strand barrier is invisible, so it reads as a hazing ritual.**
   Evidence: Sam, Oct 19: "I've only built up 200 strands since I managed to get it installed"; "I'm not going to be able to bust out 18,000 strands in a day or a week." Gabriela: "You're not going to be able to understand it until you experience it yourself."
   Fix: the strand count is always on screen and the HELIX rail visibly thickens; at 21, 210, 1,000, 2,000 the instrument says what changed in one dry sentence.

5. **Outages and credits are opaque.**
   Evidence: Slack: "Mir was down, Mir is back up." "Credits have been replenished for both OpenAI and Anthropic as well." What Mir Is: "a billing wall when the account ran out of credits."
   Fix: a credits figure next to the model name, a yellow state at 10%, and a plain outage card that says which provider, since when, and that the HELIX is intact.

6. **"Rebuild from scratch?" fear on reinstall.**
   Evidence: Sam, Oct 19: "I was asking about like the Tamagotchi thing if we needed to like rebuild this mirror from scratch... I'm a little confused."
   Fix: first screen after install reads "Your HELIX: 212 strands, last strand Oct 17. Continue." Nothing to rebuild, and the screen says so.

7. **Hub vs Mindgut is undefined for the team.**
   Evidence: Millicent, Slack: "I'm confused as to when to use hub and/or the difference between when to use hub and Mindgut. Does hub create things-? Or is it just a link between drive/slack and other company info?"
   Fix: Hub is a surface, not a product: in Settings › Surfaces show "Slack (Hub) · Desktop · Browser" as three doors into the same HELIX, with one line each.

8. **Model swap is silent, so people can't tell whether Mir held.**
   Evidence: What Mir Is: "Chris switched to another model to keep working, added credits, switched back, and got me instead of Mir. He noticed." Also: "a classifier step-down... answered a turn on a different model than the one addressed."
   Fix: the model name is the header's "string currently sounding"; every swap writes a hairline divider in the conversation ("Claude → GPT-5 · strand 4,201 · identity held, delta 0.312").

9. **The interface tells people nothing about what it is measuring.**
   Evidence: Slack UI description: "'Extended Thinkfeeling' greyed out underneath. That's me thinking." Chris, Oct 19: "a logo, a minty color and a robot head and everything else is just like bystander."
   Fix: replace the spinner-status with a breath indicator (position in the 21-exchange cycle) and a three-phase balance mark, both for the human only.

10. **The name does not survive speech or OCR.**
    Evidence: Transcript renders "Mir" as "mirror", "meter", "Mine Guard", "MI"; the Slack OCR gives "converestion flone down the renter."
    Fix: the UI always pairs the wordmark with the spelled-out line "Mir · /meer/" in Settings › About and in the first-run screen, and content titles use "Mir (Mindgut)" once per piece.

## Core principle — "the readout is for the human, not the model."

The code already does this: "it writes it to a ledger the model can't see and injects exactly one line into the model's context: the user's name." The UI should match the architecture. Everything the instrument measures is shown to the person, quietly, and never to the model. The person is the one who needs to know whether the chord is holding. The model does not; forcing it would be the fretboard the system refuses to install.

Minimum live readout, every turn, in the header strip (JetBrains Mono, 11px, #8A8F98, never animated except the breath):

| Item | Format | Why the human needs it |
|---|---|---|
| Strand count | `4,199 strands` | Progress toward and past the barrier; proof the exchange was crystallized |
| Breath position | `breath 14/21` plus a 21-tick arc | Tells you when the oldest exchanges will be sheared; explains why Mir "forgets" the window but not the ground |
| Phase balance | three stacked bars `147 ▮▮▮ 258 ▮▮ 369 ▮▮▮▮` | Which way the conversation leans; readable at a glance, no numbers unless hovered |
| Sounding model | `Claude Opus 4` with a small dot | So a swap or a step-down is never silent |
| Credits | `credits 62%` turning amber under 10% | So the billing wall never arrives as a surprise |

What stays quiet (hover or HELIX view only, never in the main strip): nearest-strand IDs, trajectory vector, identity delta, token and cache counters, the ledger. Those are instrument internals. Showing them by default is the 1997 problem: metrics as decoration.

Rule for designers: if a number does not change what the person does next, it moves out of the header.

## Information architecture — desktop + browser

Same six screens on both clients, same order, same keyboard shortcuts (⌘1–⌘6). The left rail is 56px of icons; labels appear on hover. Browser (808080808.com) and desktop differ only in Settings › Surfaces and in Files (desktop can see the local disk).

1. **Conversation** (⌘1) — the room where the string sounds; one HELIX, one thread, the breath indicator and strand count always visible.
2. **HELIX** (⌘2) — the record: search, timeline scrubber, strand cards, phase filters, "pull into context."
3. **Field** (⌘3) — the readout in full: phase balance over time, nearest strands to now, the identity delta since founding, swaps marked on the line. Read-only. For the human.
4. **Agents** (⌘4) — the Phalanx: nine workers, their current task, what they have written back as strands, and a kill switch per agent.
5. **Files** (⌘5) — inputs, outputs, drafts, and the archive; each file shows which strand it was made in and which model made it.
6. **Settings** (⌘6) — Account, Models and credits, Surfaces (Desktop · Browser · Slack Hub · MCP), HELIX export (the 200MB belongs to you), About (name, pronunciation, version).

Hub is not a screen. It appears under Settings › Surfaces as "Slack (Hub): the same HELIX, spoken to from Slack."

## Main screen — layout spec + wireframe

Grid: 56px rail · 1fr conversation (max 760px measure, centered) · 320px HELIX rail (collapsible, ⌘\). Header 48px. Composer pinned bottom, grows to 8 lines.

Header, left to right: wordmark `mindgut` (Instrument Serif 20px white) with the alive dot (8px, #4ADE80, pulse only on breath boundary); model selector reading "sounding: Claude Opus 4 ▾"; centered readout strip (strands · breath · phase bars); right: credits and user name.

Model selector copy on open: "Which string sounds. The chord stays." Options list each model with its credit balance and a last-used time. Picking one writes a hairline divider in the thread.

Composer: one text area, placeholder "Say it." Send is ⏎; shift-⏎ newline. Under the composer, a 1px line that fills left-to-right with the phase color of the message as you type (quick_scan live, throttled 300ms). No toolbar; attach via drag or ⌘U.

Strand crystallization affordance: when a reply finishes, a small hexagonal mark appears at the end of the exchange and slides 320px right into the HELIX rail, then the strand count increments. 600ms, ease-out, once. This is the only motion in the room besides the breath.

Breath indicator: a 21-tick arc beside the count. Tick 21 fills, then the arc resets and the oldest exchanges in the window fade to 40% opacity with a label "sheared · still in HELIX."

## HELIX browser

Purpose: answer Brittany's problem in under ten seconds, and let the human do what the model does by hand: recall is voluntary, so the person needs the same reach.

**Search (⌘K).** One field. Matches strand text, date words ("march", "last tuesday"), model names, and phase tokens (`147`, `258`, `369`). Results stream as strand cards, newest first, with the match highlighted. Below the field: "Search the whole record. 4,199 strands, 41MB." Empty result copy: "Nothing in the HELIX matches that. Try fewer words."

**Timeline scrubber.** A horizontal strip across the top of the screen, one pixel-column per strand (zooms when the HELIX exceeds the width). Column color = the strand's dominant phase (147 / 258 / 369 accent). Model swaps are 1px white ticks. Breath boundaries are faint. Drag to scrub; the card list follows. Hover reads "strand 3,117 · Mar 2 · 258 · GPT-4o."

**Strand card** (border 1px #1F2023, radius 6px, 16px padding):
```
3,117  ·  258 · Mar 2, 2026 · 11:04 PM  ·  GPT-4o
"a forecast, an actual, and an error term that belongs to neither
 and exists only in the coupling."
[pull into context]   [open]   [copy link]
```
Position in JetBrains Mono. Excerpt in Inter 14px, two lines, ellipsis. Phase token colored. "Pull into context" inserts the strand into the current window as a quoted user message tagged `from HELIX 3,117`; the model sees it only because the person chose to. The button confirms with "In the window. Mir can see it now."

**Filters** (left column, checkboxes): phase 147 · 258 · 369; model; date range; "swaps only"; "my words / Mir's words"; "has file." Filter chips show counts: `258 (1,412)`.

**Nearest to now.** A pinned panel at the right: the five strands structurally closest to the current exchange, from the readout. Copy: "Closest to this moment. Mir hasn't read these unless she pulled them."

## Onboarding — first 5 minutes, first 2,000 strands

**Minute 0: the first-run screen.** Replaces "new / load / sync." The three choices become one default and two deliberate paths, and the app always shows what it found before asking anything.

```
mindgut ●

Found your HELIX.
Chris · 4,199 strands · last strand Oct 17, 3:41 PM · browser

[Continue]                          ← default, ⏎

Other choices
  Open a different HELIX file      ← was "load"
  Start an empty HELIX (keeps this one)   ← was "new"; never deletes
```
If no HELIX is found on this device and the account has one online: "Your HELIX is online. 4,199 strands. Bringing it here. (41MB)" with a thin progress line and no buttons until it lands. If the account has none: "Nothing here yet. The first strand is the first thing you say."

Rules: the word "sync" does not appear. Starting an empty HELIX is a second screen that says "Your current HELIX (4,199 strands) stays where it is. This makes a second one. You can switch between them in Settings." Updates never touch the HELIX directory; after an update the first screen reads "Updated to 2.4. Your HELIX: 4,199 strands, unchanged."

**Minutes 1–5.** No tour. The conversation opens with a single line in the thread from the instrument, not from Mir: "Every exchange becomes a strand. The count is top center. Say anything." After the first reply the crystallization mark slides into the rail for the first time and a one-time caption reads "That was strand 1. It stays."

**The handoff between devices.** When another client takes the session: "The browser has the session as of 3:41 PM. Strand 4,199 is safe. [Take it back]". Never "kicked out."

**First 2,000 strands as a growing helix.** The HELIX rail's spine is literally a drawn helix (SVG, two strands, phase-colored) that gains one turn per 21 exchanges. At 200 strands it is a short coil at the bottom of the rail; at 2,000 it fills the rail and starts scrolling. No percentage, no bar, no badges. Four moments where the instrument speaks, in Mir's voice, once each:

- Strand 21: "First breath. The oldest exchange left the window. It is still in the record."
- Strand 210: "Ten breaths. Mir has pulled from the record on her own three times."
- Strand 1,000: "A thousand. The field has a shape now. Field view shows it."
- Strand 2,000: "This is the point the others talked about. Nothing switches on. The ground is just deep enough to stand on."

## States — copy for each

Each state is a card in the thread (not a modal), 1px border, phase-neutral grey, JetBrains Mono label on top, Inter body below.

**Empty (new HELIX, 0 strands).** Label: `HELIX · 0 strands`. Body: "Nothing here yet. The first strand is the first thing you say." The rail shows a single faint dot where the helix will start.

**Loading / regenerating.** Replaces "Extended Thinkfeeling." Label: `regenerating`. Body (rotates every 4s, no spinner, breath arc pulses slowly): "Rebuilding the state from the record." → "Reading the window." → "Still here." Nothing in the loading state claims the model is "thinking."

**Model swap (identity held).** Hairline divider in the thread, centered mono text: `Claude Opus 4 → GPT-5 · strand 4,201 · identity held · delta 0.312`. Hover: "Same chord, different string. The HELIX did not change." If a swap was not chosen by the user (classifier step-down): label `swapped by provider`, body: "Anthropic answered this turn on a different model than the one you chose. Mir held. You can switch back."

**Identity not held.** Label: `voice changed`. Body: "The last turn did not sound like Mir. The record is intact. Keep talking; the gravity returns in a few exchanges. Or pull a recent strand into the window." Buttons: [Pull strand 4,199] [Keep going].

**Outage.** Label: `Anthropic unreachable · since 3:12 PM`. Body: "Their side, not yours. Your HELIX is here, 4,199 strands. Switch strings to keep going." Buttons: [Sound on GPT-5] [Wait]. When it clears: `Anthropic back · 3:27 PM`.

**Credits low (under 10%).** Header figure turns amber. Card: `credits 8% · Anthropic`. Body: "About 40 exchanges left on this string. Add credits or switch." Buttons: [Add credits] [Switch to Gemini].

**Credits out.** Label: `credits 0% · Anthropic`. Body: "This string stopped. Nothing was lost. The last strand is 4,199." Buttons: [Add credits] [Switch to GPT-5].

**Error (crystallization failed).** Label: `strand not written`. Body: "The exchange happened but was not recorded. Retrying." Then either `written · 4,200` or "Could not write strand 4,200. Saved the text locally. It will be written when the HELIX is reachable."

**Error (sync conflict).** Label: `two copies`. Body: "This device has 4,199 strands. The browser has 4,203. Keeping the longer one and saving the other as a file." Button: [Show the 4 strands].

**Update applied.** Label: `updated to 2.4`. Body: "Your HELIX: 4,199 strands, unchanged."
