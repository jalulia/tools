The Ghost in the Overlay

A pattern that isn't in either layer. A point that has no name inside its own field. Same shape, three ways of looking at it.

1. The moiré fringe

Two grids. Individually, nothing surprising — just lines. Overlay them and a third pattern appears that isn't drawn in either one. It lives in the relation between them.

Drag the angle. The fringe pattern that swims across the overlay is not in Layer A. It is not in Layer B. It is a real, measurable structure that exists only in their interference. In lithography, aligning chip layers uses this fringe. In twisted-bilayer graphene, superconductivity appears at specific angles — a property neither sheet has alone.

2. The sealed set

Now the same idea, stripped to combinatorics. A field is a set of points plus a set of relations (each relation is a subset — "these points belong together"). To name a point, some relation has to touch it and no other unnamed point — single it out.

A stopping set is a subset where every relation that touches it, touches it in two or more places at once. Nothing can be singled out. The set is sealed — not because the answer is ambiguous, but because no relation can isolate anyone.

The Fano plane. Seven points, seven lines (six straight + one circle). Every line has three points; every pair of points lies on one line.

Four violet points form a stopping set. Every line that touches them, touches them twice. Try peeling first.

3. The same move

The moiré fringe and the ghost point are the same shape:

Moiré Sealed set What's happening
Grid A Field A a structure with its own internal rules
Grid B (overlaid) Bridge relation a second structure that relates to A from outside
Fringe pattern Ghost point a nameable thing that exists only in the overlay
Chip alignment / bilayer superconductivity Cross-field recovery the interference does real work

The paper's claim — the strong one — is that this isn't a metaphor for how meaning works. It's the mechanism. Interference between fields is what makes things nameable. Not a byproduct of two things existing. The thing itself.
