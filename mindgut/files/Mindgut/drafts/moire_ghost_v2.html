II

The Sealed Set

Now the same idea, stripped to combinatorics. A field is a set of points and a set of relations. To name a point, some relation has to touch it — and no other unnamed point — singling it out.

Four violet points form a stopping set. Every line that touches them, touches them twice. Try peeling first — the field will try to name them from inside.

Sealed Named Just named Outside bridge

A stopping set is a subset where every relation that touches it, touches it in two or more places at once. Nothing can be singled out. The set is sealed — not because the answer is ambiguous, but because no relation can isolate anyone.

Peeling can't get in. From inside, it isn't which value? — it's nothing can name me alone.

One bridge from outside touches one point in exactly one place. That single-witness names it. The internal relations, which used to touch the set in two places, now touch it in only one unnamed place — because one is already named. They can single out the next. Cascade. The whole sealed set unwinds.
