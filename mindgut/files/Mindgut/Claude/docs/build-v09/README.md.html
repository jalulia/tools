# Mindgut documentation · Rev 09

Current self-contained master: `Mindgut_Docs_V09.html`.

All interface examples are browser-rendered HTML/CSS or WebGL/Canvas, reconstructed from the recorded 2.2.59 frontend. Messages, tasks, files, readouts, carrier labels and viewer records are synthetic. No UI screenshots or account requests are included. The wordmark is the original brand image.

## Shared UI components

`source/ui/embed.js` exposes `MindgutUI.mount(host, view)`. The shared registry supplies workspace, account, tokens, heat, respiration, tension, helix summary, automator, folder, scanner, tasks, files, output, top bar, controls, 3D viewer, Journey and Superpose examples. `preview.css` and `preview.js` provide reusable styling and local behaviour; `viewers.py` applies synthetic fixtures to the original viewer markup and renderer. `viewers.css` adapts the viewer to its container.

The single HTML file embeds the registry, source-derived component markup, fonts and pinned Three.js 0.170.0. The source package keeps these parts separate for future component-library extraction. This is an illustrative library of UI specimens, not a connection to the product backend.

Build with `python3 build.py` (Python 3 with BeautifulSoup). Original 2.2.59 source snapshots are in `evidence/`; their account-fetch handlers are replaced during the build. `vendor/THREE-LICENSE.txt` contains the Three.js MIT license; Lekton is licensed under the SIL Open Font License.

## Preservation and publication

V07 and V08 remain in the local project. A complete pre-cleanup checkout is preserved beside this package at `../mir-gallery-preserved-before-v09`. `qa/public-cleanup-inventory.json` records original and replacement hashes for the 35 affected public files. Public archive pages use a notice and link to the current guide; personal data files contain an empty archive notice. Other artwork remains available. Git history is retained at the user's explicit request.

QA evidence is in `qa/`. Backend claims and the recorded 2.2.59 version boundary are unchanged by this presentation revision.
