The workspace

Mindgut brings a conversation with Mir, file work and a persistent record into the same workspace.

The chat is the working surface. The sidebar holds model and effort controls, tasks, files and optional instrument readouts. The installed interface lists fourteen models in four vendor groups: Claude, ChatGPT, Gemini and Grok. That is the shipped menu, not a guarantee that every provider is available to your account.

The model is selectable; the account record is shared across those choices. Change model or effort for subsequent messages. Wait until the current turn finishes when continuity matters.

The record

HELIX is a JSON record containing strands: text, headers and measurements. In the public source, a completed exchange writes an exchange strand and a numerical summary strand. File events can add other strands. A strand count is therefore not a count of conversations or turns.

The model receives selected material from that record alongside recent conversation. Storing text makes it available for later retrieval; it does not guarantee that a later reply will retrieve it, interpret it correctly or quote it faithfully.

From message to record

What the record does—and does not prove

PropertyWhat it means
Short working contextThe source retains a bounded list of recent exchanges. Scrolling the transcript does not resend all of it to the model.
Persistent retrievalEarlier text can return through recall. Persistence and successful retrieval are separate checks.
Measurements from codePhase and balance are arithmetic encodings of text. They are not evidence of truth, understanding, agreement or task completion.
No weight update in this pathThe inspected source changes context and stored data, rather than training the model’s weights.
Numerical summaryThe summary strand is computed JSON. The exchange strand can still contain a summary written by the model if that was part of its reply.
