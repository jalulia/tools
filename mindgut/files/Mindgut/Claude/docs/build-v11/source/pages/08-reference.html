How claims are bounded

Checked in source
Verified in the specified repository snapshot. The current compiled backend may differ.
Checked in frontend
The installed interface has the control or request path described. That alone does not verify the server’s handling.
Observed in app
Seen during the recorded app inspection. Historical observations inform the text; published UI counts and file lists are synthetic.
Inherited report
V05 described the behaviour or limit. This revision has not independently reproduced it.

Images and demonstrations

The guide replaces the workspace, top bar and sidebar screenshots with HTML and CSS reconstructed from the recorded 2.2.59 frontend. The UI uses the original Roboto font, colours, icons and layout rules, adapted to fit this guide. Messages, filenames, tasks and readout values are generic examples. Preview controls operate only within the example; they do not contact the app or an account. The 3D and wave viewers also run in the browser, using the original renderer with deterministic synthetic records and generic carrier labels. All UI examples share a component registry. The sidebar gallery holds transient states for inspection; the real app clears scanner results and vent lights after their recorded delays. No UI screenshots are embedded.

The diagrams are explanations, not interface replicas. The phase plot uses the actual founding record. The recall demonstration reproduces the inspected outer selection path for that record without a mounted document. Its results were compared with Python source outputs. The encoder distinguishes letter and word resolution.

Checks this review did not perform

  • No new model turn, model switch, automation run, task mutation, scan, deletion or sync experiment was initiated.
  • The hosted service was not tested independently. The example 3D and wave viewers loaded; Drift/Reset, Journey/Superpose and local animation controls were tested. Audio output was not evaluated.
  • No packaged Python was decompiled. Unreadable current backend behaviour remains an open question.
  • Keyboard, layout, search and demonstration tests apply to this documentation, not to all behaviour of the Mindgut product.
