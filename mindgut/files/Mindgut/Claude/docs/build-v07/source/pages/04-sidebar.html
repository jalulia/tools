Know what changes state

Model and effort apply to subsequent messages. Folder selects local access. Scanner requests conversion. To Do changes task state. File links access artifacts; their × controls request deletion.

Automator is desktop-only. Set 1–25 automatic replies; the default count is 7. When armed, it waits for a final reply ending with “Beep boop.” and sends “Boop beep.”. Matching ignores case and trailing whitespace or certain formatting characters. It does not recognize general expressions of permission.

Your queued messages take priority. The frontend stops or parks the loop according to turn state; it disarms on a failed turn, exhausted count, missing trigger or new session. The active button and the composer’s Stop control can stop automation. Arming can immediately continue a qualifying previous final reply. Each automatic reply is a model turn with its usual usage.

Task checkboxes and deletion requests are different actions. A task marked complete only records its state; verify the artifact separately. The folder × and file × also have different behaviour; see their lifecycle boundaries.
