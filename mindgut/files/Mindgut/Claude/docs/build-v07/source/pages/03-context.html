The working window

The visible transcript, the context sent to the model and the persistent record are three different things.

In the public source, an exchange is counted by a non-tool user message. It includes the assistant’s tool activity and response. After the seventh completed exchange, post-processing removes the oldest three exchanges and retains four. The next completed exchange brings the retained count to five.

Released exchanges can be retrieved if they were successfully written and retained in HELIX. The demo does not imply that every failed or interrupted turn reaches the record. The 21-exchange renewal counter is a separate mechanism.

Automatic recall

Before a model call, the source assembles recall information. Its outer selector chooses the first strand as origin, then up to three complement and three opposite entries, one from each eligible class. A further pass can add sentence-level material. This is not the entire record.

Complement selection uses the segment from the record’s field coordinates to the current message’s word-phase coordinates; a mounted document can add another segment. Opposite selection uses distance from the record’s field coordinates. The working demonstration shows that distinction.

V05 reported additional word-matched bridges in 2.2.58. That report is retained as historical evidence, rather than presented as a newly reproduced backend test. Retrieved material can be irrelevant; it is context to inspect, not an instruction to obey.

Deliberate recall

Mir can request earlier material with memory tools. The public source includes positional memory reads; V05 also reported concept reach and phrase search in its runtime. Their current server-side implementation and schemas have not been independently exercised here.

When a claim depends on earlier conversation, ask for the retrieved text and its strand identifier. A matching phrase proves occurrence in the retrieved material. It does not prove who endorsed it: people paste, quote, question and reject text. A search that finds nothing does not prove something was never said.

The public source shortens memory-tool results after the turn. Ask Mir to retrieve them again when exact wording matters.

Assess “I remember”

Possible basisWhat to check
Recent contextAsk which message it came from. Presence in context does not make the model’s interpretation correct.
Retrieved recordAsk for the strand identifier and exact passage. Read the passage in context.
Automatic selectionAsk whether the answer relied on recalled material, and request deliberate verification.
Inference or errorIf no source can be produced, treat the claim as unverified. Models can mistake an inference for a memory.
