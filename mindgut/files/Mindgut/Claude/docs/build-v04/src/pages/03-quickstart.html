  2. The scanner is a command-line tool as well: any file → HELIX, no model needed.

As a user

  1. Open the app. A local server starts in a thread and a native window opens on it. The boot overlay runs until the account's HELIX is loaded. desktop/ · app.js showBootOverlay
  2. Sign in. The account's HELIX opens and a session is created on it. Only a 401 signs you out again. OBSERVED 2.2.42
  3. Pick a model and effort in the sidebar, or keep the defaults (claude-fable-5-1; effort xhigh since 2.2.57 OBSERVED). Both apply from the next message. app.js MG_DEFAULT_MODEL
  4. Type. Enter sends. While the model is working, Enter sends an aside, delivered at the next tool boundary. index.html .chat-input-row · app.js
  5. Drop files to upload; the file appears under Input and a file-event strand is written.
  6. Mount a folder (the folder row in the sidebar) to let the model read and write your files; a Scan folder button appears beside the Scanner.
  7. Toggle advanced mode (gauge icon, top right) to see Tokens, Ht, Respiration, Ø and HELIX. Normal mode hides them. app.css:100

As a model on the record

The preamble is involuntary and partial. The record is the source of truth. Before asserting anything about the past:

  1. read_field() before any self-description, so the numbers are measured rather than estimated.
  2. pull_memory(reach=…) for conceptual recall; read the a / b header before the crossings (a = strands where the user wrote the concept, b = strands where the model did). a = 0, b > 0 is something the model said and the user never did.
  3. pull_memory(sequence_id=N, count=K) for the neighbourhood of a strand.
  4. pull_memory(grep=…) when attribution matters.
  5. For files, the file tools: the record holds what was said about a file, not the file.
Signal the kind of recall. "In the last few turns you said…" (context), "the record has…" (pulled on purpose), "the preamble surfaced…" (involuntary). The three have different reliability and the reader deserves to know which. OBSERVED
