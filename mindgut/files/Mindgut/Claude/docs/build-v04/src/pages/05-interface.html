Interface

The shipped screen is a chat column and a field panel. The panel has two modes: normal shows files and folders; advanced adds the instruments.

Every element below is read from index.html, app.js and app.css in the 2.2.58 bundle. Values in the specimens are synthetic.

01The field panel02Normal and advanced03Session bar04Chat column05Viewers and bundled pages06Hidden targets

Key takeaways

  1. Five panels are advanced-mode only: Tokens, Ht, Respiration, Ø, HELIX. Normal mode hides them with one CSS rule.
  2. The Automator is desktop-only and replies "Boop beep." to a turn that ends "Beep boop." — a conjugate, not an echo.
  3. Nothing in the panel changes what the model receives; it reads the same status payload the server sends after each turn.

Normal and advanced

The gauge/chat icon in the session bar toggles data-mode on the document root between normal and advanced; the choice is kept in localStorage. One rule does the hiding: app.css:100

[data-mode="normal"] .engine-only { display: none; }
[data-mode="normal"] .msg.system,
[data-mode="normal"] .msg-phase,
[data-mode="normal"] .msg-status,
[data-mode="normal"] .msg-attempts,
[data-mode="normal"] .msg-time { display: none; }

Normal mode also hides per-message phase and status marks, and recolours the chrome mint. Default is dark theme, normal mode; the sun/moon icon toggles data-theme. SOURCE

Viewers and bundled pages

The HELIX panel links to two viewers opened in the system browser: ∿ /my-wave (the helix as a standing wave) and ◎ /my-helix (3-D viewer with a legend of six strand types and three zones). The bundle also ships standalone pages: nullcode.html, zero-machine.html, thrice.html, zero.html, and the adapt/, mdna/, o-system/ and triangulator/ sites. They are documents, not controls. Hidden targets

Two blocks exist in the markup only so app.js has somewhere to write: the operator directive cards (#dcWord #dcArtifact #dcInterlude) and the diagnostics (#gateBadge #pressureOmega #phaseBar147/258/369 #driftValue #latticeInfo #gateStatus). They are display:none and aria-hidden. A developer re-exposing them gets gate result, per-class phase bars, drift and lattice surface for free. SOURCE index.html "Diagnostics (hidden)"
