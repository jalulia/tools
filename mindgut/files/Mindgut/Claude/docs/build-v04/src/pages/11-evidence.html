Interface specimens

The screens in chapter 05 are offline renderings, not screenshots of a live session. Method:

  1. Copy the bundle's index.html and app.css. Remove all five <script> elements and sixteen inline on* handlers. Inline the CSS; rewrite /static/ URLs to relative.
  2. Populate the chat with a six-message synthetic conversation ("Packaging review") using the shipped .msg classes. Account header "Example workspace"; generic model and effort menus; two example files.
  3. For the advanced specimen, set data-mode="advanced" on the root and fill the instrument values with plausible synthetic numbers; show the Automator section as desktop would.
  4. Render with Playwright driving the system Chrome, 1280×850 at 2×, offline: true, every non-file:// request aborted. Confirm document.scripts.length === 0.

Modifications are listed in MODIFICATIONS.txt beside the fixture. No live server, API or account was touched. MEASURED 2026-10-20
