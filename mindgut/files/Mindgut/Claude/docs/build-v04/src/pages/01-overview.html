Overview

A desktop and web application that keeps a persistent, measured record of a conversation and puts a fixed slice of it in front of the model on every turn.

Key takeaways

  1. The record is a file the user holds. Writing to it is deterministic code; no model is involved.
  2. The model's context is seven exchanges, trimmed to four. Everything older is reached through the record, not remembered.
  3. Models can be switched mid-session; the record is what continues.

What it is

The user talks to a persona called Mir: the name the runtime gives whichever language model is active, from one of four vendors. An effort level (low to max) sets how much work that model puts into each reply. Around it is a runtime that measures every turn, writes it into a file called the HELIX, and on the next turn selects part of that file to show the model, chosen by geometry rather than by topic.

Three things follow from that drawing and shape the rest of this document:

  • Two kinds of recall. A preamble is placed in front of the model every turn without being asked for (involuntary). The model can also read the record on purpose through tools (voluntary). Chapter 06 covers both.
  • A short, breathing context. The model sees the last seven exchanges verbatim; at seven, the oldest three are cut and it continues with four. This is called PAR respiration and is exchange-counted, not token-counted. config.py:24–30
  • One record, many models. The sidebar switches the underlying model and the effort level from the next message on. Session, history and HELIX continue. OBSERVED app.js · MG_MODEL_GROUPS

The arithmetic underneath

Every letter A–Z is numbered 1–26 and reduced to its digital root. The root falls into one of three classes: A {1, 4, 7}, R {2, 5, 8}, D {3, 6, 9}. Non-letters are ignored. For any text, the three fractions of letters per class form a phase vector; their standard deviation across a window is σB; A minus D is balance. These are what the runtime measures, stores, recalls by, and trims by. SOURCE scanner.py:40–70 · sigma_b.py:41–160

Across a 370,105-word list the three classes hold 33.41 / 33.32 / 33.28 % of letters, so a deviation from one third is signal and not an artefact of the alphabet. Whether the encoding carries meaning is the author's theory (Paradox Field Dynamics), which ships as a 774-strand book inside the app. This document describes the arithmetic and leaves the theory to that book. sigma_b.py:18–21
