Key takeaways

  1. A HELIX read is stubbed after the turn: the context never re-absorbs what the record holds.
  2. Stale tool results over 3,000 characters are cut to 1,500 after two rounds.
  3. Large single-parameter writes are the one documented way to lose work; open + append is the designed path.

Writing files safely

The tool descriptions say it directly: do not emit whole files as a single parameter. A mid-generation truncation of a multi-kilobyte string destroys the write silently; a partial draft on disk can be resumed. The designed path is open then append in ~1–2 KB chunks, then finalize for drafts. The sandbox's home directory is the app's account directory, not the machine user's. OBSERVED

draft(action="open",     filename="spec.md")
draft(action="append",   content="…≤ 2 KB…")   # repeat
draft(action="finalize", filename="spec.md")   # → outputs/spec.md
