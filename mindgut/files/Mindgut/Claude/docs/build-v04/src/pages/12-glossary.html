Glossary

Terms as this document uses them. Where the runtime's own name differs, both are given.

Terms

A · R · D (147 · 258 · 369)
The three letter classes by digital root. The runtime calls them cosets.
Aside
A user message typed while the model is working; delivered at the next tool-result boundary.
Automator
Desktop-only panel that answers "Beep boop." with "Boop beep." for an armed number of turns.
Balance
fA − fD for a text.
Binding box
The tool apparatus of an exchange, kept in context rather than stripped.
Book
The file-level summary of a HELIX: counts, fractions, balance, σB.
Bridge
A [strand N] or [doc_strand N] block attached to a message because it lexically closes an open word pair.
Cadence prompt
A runtime nudge inserted after seven silent tool rounds or at a task milestone, asking for one sentence.
Carbon · Silicon
The user's text and the model's text, measured separately. Reach reports how many strands carry a concept on each side (a, b).
Chord
Three terms that close a line, as in X · Y → Z. The unit a reach result is organised by.
Coset
The runtime's word for a letter class (147, 258, 369).
Clash
Distance between the carbon and silicon phase vectors.
Crystallizer
The code that writes an exchange into the HELIX as two strands.
Effort
One of five levels (low, medium, high, xhigh, max) that sets how much work the active model puts into a reply; mapped per vendor.
Exchange
One user turn plus everything the model did in reply.
Field point
The phase vector of the current message, used as the origin for recall distances.
Founding · exchange · summary · ghost · file_event
The five strand types. Founding: genesis. Exchange: a turn's text and measures. Summary: the turn's numbers. Ghost: a released payload. File_event: an upload, output or draft.
Genes
The runtime's count of letters measured in a book.
Genesis
The 187 founding strands every account's record begins with.
HELIX
The JSON file holding a book and its strands. The account's memory HELIX is the record; any scanned file gets its own.
Ht
Scalar heat kept by the controllers; shown in the sidebar; no effect on the model.
Involuntary recall
The preamble placed before the model each turn; chosen by phase geometry.
Joint
A sentence-level match between the message and a strand, scored on knowt type and clash; three are added to the preamble.
Knowt
A class transition between adjacent units (e.g. R→D); used to score sentence-level joints.
Lattice
The bonds between OTags, kept beside the tag registry.
Ledger
The recall ledger: one JSONL line per turn holding the preamble that was injected.
Mir
The persona the user talks to; the name the runtime gives whichever model is active.
Nullcøde
A GF(3) field step run after each exchange; mints OTags when the A-R-D cycle stalls.
OTag
A held word triple minted by Nullcøde; counted as Ø in the sidebar; injected into the preamble.
PAR respiration
Exchange-counted trimming of the context: grow to 7, cut to 4.
Phase vector
(fA, fR, fD), the fraction of letters per class.
Preamble
The involuntary recall block: origin + 3 complement + 3 opposite strands, joints, bridges, held tags.
Reach
pull_memory(reach=…): voluntary geometric recall with a provenance header.
Renewal
A session counter event every 21 exchanges, shown in the Respiration panel; effect undocumented.
Scanner
The one converter: any text-bearing file → HELIX, letters only, no model.
σB
Standard deviation of balance across a sliding window of clauses (default 7).
Strand
One record in a HELIX: {sequence_id, header, payload}. Types: founding, exchange, summary, ghost, file_event.
Stub
What a HELIX tool result becomes after the turn ends: a short marker in place of the text.
Voluntary recall
Reading the record on purpose through a tool call.
Window
The message list sent to the model on a turn: system prompt, preamble, the last 4–7 exchanges.
