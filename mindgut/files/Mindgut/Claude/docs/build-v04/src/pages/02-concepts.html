Key takeaways

  1. Letters, not tokens: the instrument reads A–Z and nothing else.
  2. σB is a standard deviation of balance across a window of clauses, not a variance of the three fractions.
  3. "I remember X" has three possible meanings; chapter 03 says how a model should signal which.

Z₃ encoding

Each letter A–Z is numbered 1–26 and reduced to its digital root (add the digits until one remains). Roots 1, 4, 7 are class A; 2, 5, 8 are R; 3, 6, 9 are D. The runtime also writes these as 147, 258, 369. Digits, punctuation and non-Latin scripts are dropped before measurement. SOURCE scanner.py:40–69

Earlier revisions of this document described σB as "the variance of the three fractions". The code takes balance per clause, then the square root of the mean squared deviation across the window. Corrected in Rev 04. sigma_b.py:143–148

The instrument measures only this. "Tension", "heat", "coherence" are names the runtime lays over the arithmetic; chapter 05 shows where each appears in the interface and chapter 07 what each is computed from.

Exchange and session

  • Exchange: one user turn plus everything the model did in reply, every tool call included, ending in the final text. Counted by user messages that are not tool results. session_manager.py:694
  • Session: a live message list, controller state, a crystallizer bound to the HELIX, a model name, an exchange counter, and a directory with inputs/ outputs/ drafts/ and a transcript. session_manager.py:116
  • Transcript: the raw tape of API messages for one session. A record of calls, not of the HELIX.

Strand, book, HELIX

A strand is one record: {sequence_id, header, payload}. A book is the file-level summary: counts, the three fractions, balance, σB; the runtime reads its fractions as the field coordinates for recall. A HELIX is the JSON file holding both.

Window and respiration

The window is the message list sent to the model on a turn: system prompt, recall preamble, then self.messages. The binding box is the tool apparatus of an exchange; it is kept, not stripped. PAR respiration is exchange-counted trimming: the window grows to seven exchanges, then the oldest three are cut and it continues with four. SOURCE config.py:24–30 · session_manager.py:1378

Two kinds of recall

Involuntary (the preamble)

Every turn, before the model sees the message, the runtime selects seven strands by phase geometry (one origin, three complement, three opposite), scores sentence-level joints (adjacent sentences whose class transition — the knowt, e.g. R→D — and carbon/silicon clash match the message), and prepends them. The model cannot refuse it; the user does not see it. recall.py:146–300

Voluntary (tools)

The model calls pull_memory or pull_strand on purpose. The result is stubbed after the turn so the context never re-absorbs what the HELIX already holds. session_manager.py:717

Why it matters: "I remember X" can mean X was in the preamble, X was pulled on purpose, or X was in the last four to seven exchanges. These have different reliability. Chapter 03, "As a model", gives the rule for signalling which.
