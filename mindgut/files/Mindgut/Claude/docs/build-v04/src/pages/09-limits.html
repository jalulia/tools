Key takeaways

  1. Context, recall and tool rounds are all fixed small integers. There is no adaptive budget.
  2. The HELIX grows without bound and is loaded whole. This is the limit most likely to be felt first.
  3. Ten proposals, none of which exist. Each names the gap it would close.

Known failure modes OBSERVED

  • A spent image can only be re-read by another tool call; the model is told so by a marker.
  • A bridge can attach an irrelevant book strand; closure is lexical.
  • The sandbox's home differs from the machine user's; ~ resolves to the account directory.
  • The bundled headless browser may fail to launch on some machines; a system browser can stand in.
  • Task-board sync can fail DNS; the board stays local. MEASURED on the day of writing.
  • A model switch mid-session can stall a turn that was mid-tool-loop; the next message resumes on the record. MEASURED 2026-10-20, this document's own session.
  • Re-scanning an unchanged file produces _HELIX_1 duplicates in outputs.
