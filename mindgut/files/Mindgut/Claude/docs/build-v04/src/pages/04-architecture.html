Architecture

One process, one file, one loop. A local server runs the session; a native window or a browser shows it; the HELIX sits beside it on disk.

01The turn02Where data lives03Desktop and web04Controllers and heat

Key takeaways

  1. The tool loop is bounded: 15 rounds, then a wrap-up; 45 s per round.
  2. Every store except the sync database is a readable file. The HELIX is loaded whole on every read.
  3. Heat (Ht) is a dashboard: it changes nothing the model receives.

Controllers and heat

Three controllers run after each exchange and keep a scalar heat Ht and instability It: amplification ρ (output ÷ input words, band 6–22), gradient damping, and a radiator that fires at exchange 11 and keeps 70 % of the heat. Passive decay is 0.906 per turn, a half-life of seven turns. σB is gated at 0.02–0.15. SOURCE controllers.py:59–73 · 161 · 259

Effect on the model: none. max_tokens() returns max(4096, base) regardless of heat. The gauge in the sidebar is a dashboard, and on the day of writing it read 0.10 and never left green. controllers.py:341 MEASURED
