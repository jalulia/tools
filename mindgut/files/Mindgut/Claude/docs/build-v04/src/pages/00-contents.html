Mindgut

A language model wrapped in a measured, persistent record of the conversation. This document describes the runtime at build 2.2.58: what it stores, what it puts in front of the model, what the interface shows, and what a developer can change.

Written for a developer or designer who has not seen any conversation. No personal information appears; interface specimens use synthetic content.

How claims are marked

  1. SOURCE read in code or configuration; cited file:line.
  2. MEASURED a number the system recorded: a log, a HELIX field, a live reading.
  3. OBSERVED seen from inside the runtime or inferred. May be wrong; says so.
  4. PROPOSED does not exist. Kept in chapter 09 only.
