Terms

A / R / D
Classes of digital roots: 147, 258, 369. Names used in the code do not prove the semantic character of text.
Aside
A message queued while Mir is working; delivered at a supported processing boundary.
Automator
The desktop continuation loop that sends a fixed reply after a qualifying final trigger.
Balance
A share minus D share, at a stated letter or word resolution.
Bridge
Additional retrieved context reported by V05 as attached through word matching. Current backend details are not reproduced here.
Carbon / silicon
Runtime labels for user and assistant text or measurements. These labels do not establish authorship of quoted or pasted content.
Complement
Up to one candidate per class nearest the active source recall segment(s), including the position term.
Effort
A frontend level applied to subsequent model calls; five labels are available.
Exchange
A user message and the assistant activity in response. Source counting uses non-tool user messages.
Field point
The record-level f147/f258/f369 fractions used as the fixed reference in the outer selector.
Founding
The shared starting record: 187 strands in the installed bundle.
Ghost
A strand whose payload is released or absent; remaining metadata is not the original text.
HELIX
A JSON record with book-level information and a list of strands. Account memory and scanned documents are separate records.
Hₜ
Computed heat displayed in advanced mode. Its full current backend role is unverified.
Joint
Sentence-level material selected by a further recall pass, outside the outer-selector demo.
Letter phase
The three shares of accepted letters, classified one letter at a time.
Mir
The assistant encountered through Mindgut, with a selectable model behind the conversation.
Opposite
Up to one candidate per class with greatest scored distance from the record’s field point.
Organic
Strands added beyond the founding population; purple in the dark-theme capture.
Origin
The first strand selected by the source’s outer recall path.
Phase
A three-component class distribution. State whether it is measured over letters or words.
Recall
Material selected or requested from a stored record for use in a later turn.
Renewal
A separately reported session event at 21-exchange intervals in the captured app; backend effects remain unverified.
Respiration
The working-window cycle. In source, seven completed exchanges trigger trimming to four.
Scanner
The converter from supported text-bearing files into HELIX structure.
σB
Population standard deviation of clause balances over up to seven nonempty clauses in the streaming instrument; zero with fewer than two.
Strand
A record unit with an identifier, header and payload; formats can carry additional fields.
Summary strand
Computed numerical JSON appended by the source crystallizer, distinct from a model-written prose summary.
Tension tag / Ø
Structural word-pattern state held by the source state machine; Ø displays the active count.
Window
The recent exchange list. System instructions, recall material and the current message also contribute to the full model context.
Word phase
Classify each A–Z word by the digital root of its summed letter roots, then count the class proportions.
Worker
A separate background task process, distinct from Automator’s main-conversation continuation.
