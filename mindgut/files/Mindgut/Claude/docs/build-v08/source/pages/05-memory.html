A record made of strands

HELIX is a structured JSON record. On successful crystallization, the source appends an exchange strand and a numerical summary after a completed exchange.

The installed founding file contains 187 strands. Later exchanges and file events add to the account record. Normal crystallization appends strands and updates book-level aggregates; it is not an immutable audit log, and “nothing is rewritten” would overstate what the file format guarantees.

The source loads the file whole. Size depends on text and metadata; V05’s roughly 8 KB per exchange came from one reported sample and is not a fixed storage budget. Local paths, sync and archive retention in the current compiled backend require separate verification.

Two measurement resolutions

For A–Z, number the letter from 1 to 26, then reduce its position to a single digit. Roots 1, 4 and 7 map to A; 2, 5 and 8 to R; 3, 6 and 9 to D. “N” is 14 → 5 → R.

Letter phase is the proportion of accepted letters in those three classes. Word phase first sums a word’s letter roots and reduces that sum, then counts one class per extracted A–Z word. These are different measurements. The public source retains both; its recall selector uses the word-level fields f147, f258, f369.

Balance is A share minus D share. In the source’s streaming instrument, σB is the population standard deviation of clause balances over up to seven nonempty clauses. With fewer than two clauses, the implementation returns zero; that is not evidence of perfect coherence.

Character counts and word extraction have separate A–Z rules. Numbers and most other scripts do not contribute. These encodings do not establish meaning, truth, authenticity or psychological state.

What a strand holds

sequence_idThe top-level strand identifier, re-anchored to max existing ID + 1 before crystallization.

payloadFor an exchange, user text, a separator and assistant text. The summary payload is JSON of computed measures.
Additional fieldsScanned-document records can include atoms, word maps and sequences. Do not assume every HELIX has an identical schema.

Recall, with the source geometry

For complement selection, the public source scores eligible speech strands against the segment from the record’s field point to the message point, one bucket per stored class. For opposite selection, it scores distance from the record’s field point. A small position term breaks geometric ties and slightly changes the score: it favours later strands for complement and earlier strands for opposite. The origin is the first strand.

At most one candidate per class is selected for each group; an empty bucket yields fewer. Seven selection entries need not mean seven distinct strands. An absent or nearly coincident message point triggers the source’s radial fallback. A mounted document adds another axis; that path is outside this demonstration.

Tension tags

The source feeds word classes to a ternary state machine. A stalled cycle can mint a tag from words in the text; held tags are carried as structural state. The Ø panel shows a count. It does not show the tags or explain which human question, if any, they concern.

The viewers

The HELIX panel links to /my-wave (“the helix as a standing wave”) and /my-helix (“View HELIX in 3D”). They open separate views. Both views loaded the current account through the local desktop server during this review. In the 3D viewer, Drift changed the geometry and Reset returned the view. In the wave viewer, Journey and Superpose produced visibly different arrangements. Playback and sound were not evaluated.
