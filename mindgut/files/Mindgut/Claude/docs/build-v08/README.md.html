# Mindgut documentation V08

Open `Mindgut_Docs_V08.html`. The document is self-contained and works offline.

The workspace, homepage UI specimens, sidebar explorer and top bar are coded HTML/CSS with generic messages, tasks, files and counts. Their visual source is the preserved Mindgut 2.2.59 frontend in `evidence/`. The native Roboto font and Mindgut wordmark are embedded; the wordmark is an original graphic asset, not a screen capture. The 3D and wave viewer evidence images from V07 remain labelled captures.

`source/pages/`, `source/style.css` and `source/app.js` contain the guide. `source/ui/` contains responsive adaptations, local example interactions and the shared embed renderer. `build.py` assembles the original interface markup with generic content and embeds assets; it writes only inside this folder. Rebuild with `python3 build.py` (requires BeautifulSoup 4). The recorded product JavaScript is never executed and no product API, storage, files or microphone are accessed.

QA lives in `qa/`: desktop and mobile renders; all eleven guide routes checked at four widths; every sidebar specimen checked; focused final checks for the changed views; local mode/theme/sidebar/task/stop controls and expanded view verified. An early timing-based sidebar check sampled its animation; final checks wait for the completed transition and pass.

V07 remains preserved. This revision changes the UI examples and related presentation text, not the technical evidence boundary.
