## Faults found and patched
1. Canvas plates painted before fonts loaded (serif fallback) → plates draw after `document.fonts.ready`.
2. SVG `<text>` CSS fill overrode per-element fills (white-on-blue headers invisible) → fills via `style`, CSS only as fallback.
3. Phone: masthead `.two`, kv table `code{nowrap}` and the quickstart `ol{max-width:none}` overflowed 390 → wrap rules; `html,body{overflow-x:hidden}` under 980; rail collapses to two columns; card rows stack. Document width now 390 = viewport.
4. Preamble plate still carried V02's violet/blue → chapter accent + neutrals.
