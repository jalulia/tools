# D-003 · walkthrough-v01-rulings

- **Date:** 2026-10-20
- **Decided by:** Julia
- **Status:** accepted

## Decision
On the first Mindgut walkthrough (V01, cyanotype): the surface is rejected — "too blue / blueprinty / watercolory" — and **Fraunces is banned** for this work. The structure is liked ("I like it, but it's not refined enough to be viable"): the plates, the record-driven helix, the optics, the proposed/existing tagging carry forward.

## Accepted / rejected / why
| Accepted | Rejected | Reason |
|---|---|---|
| near-black instrument ground, paper-white ink, one lamp accent | Prussian-blue wash, brushed paper margin, process grain | too blue; reads as blueprint and watercolor |
| Archivo (500 / 300) for text, JetBrains Mono for the machine | Fraunces | banned by Julia |
| three phase sinusoids (a helix seen from the side) | horizontal rungs by phase angle | the rungs read as a bar chart |
| refinement before new ideas | more plates | "not refined enough to be viable" |

None. Narrows `fidelity.md` §12 for Mindgut: the encyclopedia type stack is a calibration bar, not a palette to draw from here.
