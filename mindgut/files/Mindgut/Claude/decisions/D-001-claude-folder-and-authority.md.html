# D-001 · claude-folder-and-authority

- **Date:** 2026-10-19
- **Decided by:** Julia (requested); Claude (structure proposed)
- **Status:** accepted

## Decision
`Mindgut/Claude/` is the Claude working area for the Mindgut project. All Claude-produced Mindgut work is created, versioned and logged here under `PROTOCOL.md`, and judged against `fidelity.md`. Everything else in `Mindgut/` is read-only from here: the harness stores (`inputs/`, `outputs/`, `sandbox/`, `helixes/`) and other lineages (`Coffee/`, `Cookt/`, `JECA/`, `Ki/`, `Mad Money*/`, `drafts/`, `encyclopedia/`).

## Accepted / rejected / why
| Accepted | Rejected | Reason |
|---|---|---|
| Honest version numbers (`_V0N`), never overwrite, `NOW.md` as the only current pointer | `latest.html` slot copies, `final`/`(1)` names | one canonical home; drift must be loud |
| Quarantine-only authority, dated manifests | deletion by Claude | Julia does the final pass; nothing is lost |
| Provenance vocabulary from the Ø Operating Spec + `known_failure` | a new parallel vocabulary | the dossier forbids inventing one; `known_failure` is needed for paired decisions |
| File-based protocol, git optional | git required | the remote shell cannot clear `.git` locks; git can be added from the Mac later without changing the rules |

## Supersedes
None.

## Consequences
`NOW.md` lists current versions; `UPDATE_LOG.md` is written every session; `tools/verify.py` is the drift check. Prior Mindgut outputs are `historical` until D-002.
