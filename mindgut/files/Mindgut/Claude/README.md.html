# Mindgut / Claude

Claude's working area for the Mindgut project. Set up 2026-10-19.

**Start here, in this order:**
1. `NOW.md` — what is current, what is mid-flight, what needs a decision.
2. `UPDATE_LOG.md` — the last changes (newest first).
3. `PROTOCOL.md` — files, versions, records. How work moves.
4. `fidelity.md` — the craft standard. The bar is high; it is the release gate.
5. `brief/Mindgut_Brief_V01.md` — the brief as received.

**The rules in one breath:** read the log first, write the log last · never delete, never overwrite, bump the version · nothing is judged unrendered · everything outside this folder is read-only · design is of the content, no house style · reject anything that would survive a logo swap.

```
Claude/
├── README.md            front door (this file)
├── NOW.md               status board — current versions and open decisions
├── UPDATE_LOG.md        change log — mandatory, newest first
├── PROTOCOL.md          versioning · editing · records · verification
├── fidelity.md          craft standard — material, surface, type, color, layout, motion, UI, front end, process + JSON spec
├── brief/               the brief (V01) and dated addenda
├── references/          reference canon — one entry per reference with editorial status
├── studies/             ST-NN-slug/ high-fidelity studies, versioned
├── work/                W-slug/ resolved pieces: hero, conversation, HELIX, site, social, ads
├── presentation/        the visual sequence, versioned
├── decisions/           D-NNN-slug.md decision records
├── reviews/             YYYY-MM-DD-slug/ render-and-critique passes
├── tools/               verify.py · snapshot.py · log.py · render.js
├── _archive/            dated snapshots of superseded versions (never deleted)
└── _quarantine/         doubtful files with MANIFEST.md, awaiting Julia
```

Parent protocol for the whole Mindgut folder: `../PROTOCOL.md`, map `../README.md`, status `../NOW.md`.

Verify the folder: `python3 tools/verify.py` (exit 0 = clean).
