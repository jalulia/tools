# ST-04 · build

`python3 build.py` → `../ST-04-distance_V01.html` (the version comes from `spec.json`). Inputs: `src.html` (the page), `plate.js` (the renderer: `PLATE.render(canvas, W, H, view, layers, seed)`, `PLATE.renderThumb`, `PLATE.geometry`, `PLATE.PAL`, `PLATE.MARKS`, `PLATE.PERSON`), `spec.json` (concept · words · form · style · pass order · operators · critique loop · tests), `font_Archivo.txt` + `font_JetBrains_Mono.txt` (woff2 data URIs, the boards V05 faces), `../ref/b171ef59ad6729c08f130fb0798ae6f3.png` (pin 048, for the family check; falls back to `references/_pins-2026-10-20/`), `loop/pass-1.png` + `loop/pass-2.png` (the critique-loop renders, embedded as 560-px JPEGs).

Loop tools: `shot.py out.png [view=x0,y0,x1,y1] [z=] [off=layer,…] [thumb=a|b|c|d] [seed=]` renders `test.html` headless and prints luminance/dark-share; `render.py file.html outDir [w h]` renders the built page (full + per-section PNGs, console-errors.txt, requests.txt, overflow check). No reference comparison: this study is built from the concept end; the family check against pin 048 is computed in the page.

Two builds produce identical bytes (sha256 confirmed 2026-10-23).
