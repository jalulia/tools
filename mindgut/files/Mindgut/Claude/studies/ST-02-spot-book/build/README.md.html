# ST-02 · build
`python3 build.py` → `../ST-02-spot-book_V01.html` (bump the version in the output name for a new version). Reads `src.html` + `plate.js` + `spec.json` + the two font data URIs + the pin from `references/_pins-2026-10-20/` (as a JPEG q93).
`python3 render.py ../ST-02-spot-book_V01.html <outDir> [w h]` — full page + per-section PNGs + console-errors.txt + requests.txt (Python Playwright; same contract as `tools/render.js`).
`python3 shot.py out.png [view=x0,y0,x1,y1] [z=…] [off=layer,…]` — renders `test.html` (the plate alone) and compares it to the same crop of the pin: writes `out_ref.png`, `out_sbs.png` (reference · rebuild · |Δ|) and prints the metrics.
`python3 masks.py render.png out.png [classes…]` — colour-class mask overlays, pin = red, rebuild = cyan, both = white, with IoU per class.
Never hand-edit the built file.

V02: `python3 measure.py` writes `measured.json` (object contours + page-line traces from the pin); `build.py` inlines it as `MEASURED`. `test.html` loads `measured.js` for the loop — regenerate it with `python3 -c "import json;open('measured.js','w').write('const MEASURED = '+json.dumps(json.load(open('measured.json')))+';')"`. `shot.py` and `masks.py` take `ref=<png>` (and `shot.py` `plate=<js>`) so they serve any study.
